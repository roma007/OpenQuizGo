## 说明

- 该结果是本地单机、读多写少场景，用于验证服务框架与查询路径；

- 答题/会话接口有设备级限流（3 次/10 分钟），全链路压测前需在预发关闭限流或使用多设备令牌。

## 复现

```bash
go build -o bin/loadtest ./cmd/loadtest
./bin/loadtest -base http://localhost:8080 \
  -path /v1/child/context -token <DEVICE_TOKEN> \
  -rate 1000 -duration 10s -concurrency 300
```
