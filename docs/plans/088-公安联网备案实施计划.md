## 1. 背景与目标

- 法规：《计算机信息网络国际联网安全保护管理办法》第十一条——网络正式联通之日起 **30 日内** 到属地公安机关办理备案。
- 现状：ICP `粤ICP备2026058093号-2` 于 **2026-11-23** 通过；公网 80/443 于 **2026-11-24** 开通（086 已收尾）。
- 截止：**2026-12-23 前**必须提交（留出退回补正的余量，建议 11 月底前提交）。
- 不能豁免：平台允许「网站仅提供 API 接口服务、无面向用户网页内容」免办，但我们有 `atlas.openapp.asia` 静态站与 `quiz.openapp.asia` 管理后台页面，**必须办**。
- 目标：在 `beian.mps.gov.cn` 提交并取得 `粤公网安备 4401XXXXXXXXXXXX号`，通过后 30 日内挂到两站页脚。

## 4. 步骤

> **执行顺序**：先做 **T2（注册/登录 + 实人认证）**，再做 **T1（绑定数据码）**；
> 只有拿不到数据码时才走 T3 → T4 手工填写。编号按依赖写，不按先后。

### T1 绑定数据码（已确认有码，走这条）

> ⚠️ 数据码等同于「以你的身份认领这条备案」的凭据，别发到公开群/仓库；本轮归档时已按敏感信息处理。

1. 用刚注册的**个人账号**登录 <https://beian.mps.gov.cn/>（实名必须与 ICP 主体负责人一致）；
2. 登录后若自动弹出「绑定数据」对话框 → 选 **绑定数据码** 页签；没弹出就点页面**右上角「数据码」**；
3. 填 **数据码**，再填 **负责人手机号或身份证号**（与 ICP 备案一致的那个；系统能自动匹配时可留空，但填上更稳）；
4. 点 **确认** → 进入「绑定数据」页面，可看到 **创建主体** / **创建网站** 两个按钮。

#### T1 之后：创建主体 + 创建网站

- 点 **创建主体** → 自动生成主体草稿并跳到「新增主体」→ 核对个人信息（姓名/证件号/手机/住址/证件照片），提交；
- 点 **创建网站** → 自动生成网站草稿并跳到「新办网站申请」→ 已带入的字段（网站名称/备案号/域名/服务内容/语种/IP）核对无误，

### T3/T4 备用路径：没有数据码时手工填写

数据码只在 ICP 提交时选了「同意授权同步」才会生成，不可逆。本项目**已有数据码**，
下面两步仅在绑定失败（如提示「数据不存在」且无法解决）时使用：

- **T3 新增主体**：业务办理 → 新增主体 → 主体性质「个人」→ 填负责人信息（姓名、身份证号、证件有效期、手机、邮箱、住址、证件照片）；
- **T4 新办网站申请**：按**第 2 节**全部字段手工填写 → 网站负责人勾「同主体负责人」。

> 绑定报「数据不存在」时先核对两件事：证件号码与 ICP 主体负责人**完全一致**；
> 手机号用的是 ICP 备案里的**主要联系电话**（不是应急电话）。

### T2 注册 / 登录 + 实人认证

1. 打开 <https://beian.mps.gov.cn/> → 用户登录 → 注册账号（个人注册）；
2. 扫码下载「公安一网通办」APP → 扫页面二维码做人脸认证；
3. 若认证后被跳到「公安部互联网+政务服务」平台，**重新访问 `https://beian.mps.gov.cn/` 再点用户登录** 即可。

### T3 新增主体

业务办理 → 新增主体 → 主体性质「个人」→ 填负责人信息（姓名、身份证号、证件有效期、手机、邮箱、住址、证件照片）。

### T4 新办网站申请

按第 2 节填「网站基本信息」→「网站负责人」（勾同主体负责人）→ 下一步。

### T5 提交

阅读《互联网信息服务单位网络安全责任告知书》，勾选承诺 → 提交。
安全评估：ICP 与公安备案默认不要求（应用商店才可能要），我们暂不做。

### T6 等审核

属地（广州）网安审核，一般 **3–20 个工作日**，可能电话核实网站用途。
期间**不要改 DNS、不要换 IP、不要下架站点**（审核要能打开网站）。

### T7 备案号上线（我来做）

1. 通过后在平台「已备案网站」详情里复制 **公安备案号** 与 **HTML 代码**，下载 **备案图标**；
2. 你把备案号发我（格式 `粤公网安备 4401XXXXXXXXXXXX号`），我改两处：
   - `admin-web/src/components/Beian.tsx`：在 ICP 备案号下方加一行，链
     `https://beian.mps.gov.cn/#/query/webSearch?code=<纯数字码>`，随下次 `deploy.sh --with-admin-web` 上线；
   - Atlas 静态站：走 `/srv/ops/requests/` 给 Atlas 建一条请求（页脚同样加一行），由 Atlas 上线；
3. **取得备案号后 30 日内**必须挂上，逾期会被通报。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 手机号 / 身份证与 ICP 备案不一致 | 绑定数据码会提示「数据不存在」；改用 ICP 备案里的联系手机号与证件号 |
| 网站名称与 ICP 不一致 | 直接退回重填；照抄 `开放应用记录` |
| 误以为「只有 API」可免办 | 我们有网页内容，必须办；别赌 |
| 审核期间动 DNS / 换 IP | 触发变更备案、延长周期；审核期冻结基础设施改动 |
| 通过后忘记挂页脚 | 30 日内挂；设提醒（`docs/deployment-todo.md` 已登记） |
| 主体性质选错（个人 vs 单位） | 以 ICP 备案主体为准；选错需注销重来 |
