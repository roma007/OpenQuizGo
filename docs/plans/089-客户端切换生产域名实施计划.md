## 1. 目标与范围

把家长端（Flutter）与电视端（Android）的**默认**服务端地址切到 `https://quiz.openapp.asia/`，
保留构建参数覆盖用于本地联调。不包含：证书 pinning、多域名兜底、应用商店上架（另见 APP 备案）。

## 3. 依赖与顺序

T1、T2 可并行 → T3 → T4 → T5 → T6（T6 需要真实设备，由用户执行）。

## 4. 验证方式

```bash
# 家长端
cd parent && dart analyze lib test

# 电视端（debug 允许明文，release 禁明文）
cd tv && ./gradlew :app:assembleDebug
cd tv && ./gradlew :app:assembleRelease      # 无 keystore.properties 时回退 debug 签名，仅供内部验收

# 产物内地址核对
cd tv && unzip -p app/build/outputs/apk/release/app-release.apk classes.dex | strings | grep -o 'https://quiz.openapp.asia/' | head -1
```

装机后服务端侧确认：

```bash
ssh quizgo 'cd /srv/quizgo && docker compose logs --tail=50 api | grep -i "v1/meta"'
```

## 6. 回滚方案

单点回退：把两处默认值改回原值（`http://127.0.0.1:8080/` / `http://100.65.110.80:8082/`），重新出包。
不影响服务端；不发服务端版本即可回退（`deploy.sh` 无需执行）。
