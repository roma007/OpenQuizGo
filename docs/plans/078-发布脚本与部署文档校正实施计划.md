## 4. 验证方式

- 静态检查：`bash -n scripts/*.sh`；`git ls-files -s scripts/` 检查权限位。
- 服务器验收：
  - `ssh quizgo 'systemctl list-timers "quizgo*" "tailscale-aliyun*"'` 两个 timer 有下次触发时间。
  - `ssh quizgo 'sudo systemctl start quizgo-backup.service'` 退出码 0 且 `/srv/backup/pg` 新增文件。
  - `ssh quizgo 'sudo iptables -S ts-input | grep 100.64'` 有且只有一条 `-i eth0 -j ACCEPT`。
  - `curl -s http://quizgo-ecs:8082/v1/meta` 版本等于 `VERSION`。
- 手工验收：`scripts/deploy.sh --dry-run` 输出 6 个阶段且不产生副作用。

## 5. 回滚方案

- 触发条件：发布后 `/v1/meta` 版本不符、api/worker 起不来、健康检查失败。
- 回滚步骤：
  ```bash
  ssh quizgo 'docker tag openquizgo:rollback openquizgo:local'
  ssh quizgo 'cd /srv/quizgo && docker compose up -d --no-build'
  ```
- 数据兼容性：本次不含迁移，回滚只回代码；备份已由 `deploy.sh` 自动完成。
