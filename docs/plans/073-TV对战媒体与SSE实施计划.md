## 2. 验证方式

- `go test -p 1 ./...`（测试库 + Redis）；
- `go vet ./...`；
- TV `:app:testDebugUnitTest`、`:app:assembleRelease`；
- 运行 API 后用临时设备令牌验证 SSE：
  - 无令牌 401；
  - 他人/不存在对局 404；
  - 本孩子对局返回 `id: 0` 与 `data: {"version":0}`。
