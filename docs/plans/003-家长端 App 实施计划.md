## 1. 目标与范围

### 1.1 交付目标

交付可安装的 Flutter 家长端 MVP，与服务端 v0.1.0、TV 守护端 v0.2.0 联调通过：

- 登录 → 绑定电视 → 配置规则 → 查看报告；
- 远程解锁：家长签发观看时间，电视阻挡页 5–10s 内自动放行；
- Android APK 可安装；iOS 工程可构建（签名另议）。

### 1.2 范围边界

**包含**：家长端 App、远程解锁服务端接口与迁移、接口文档更新、联调与验收。

**不包含**：推送通知、应用商店上架、管理端题库、iPad 专版、多语言。

## 4. 验证方式

- 单元/组件测试：`flutter test`；服务端 `go test ./...`；
- 接口联调：curl + App；
- 手工验收：
  1. dev 短信登录；
  2. 新增孩子「测试孩子」；
  3. 输入电视激活码绑定；
  4. 设置规则（20 分钟 / 门槛 3 / 均衡），PIN 确认；
  5. TV 播放 → 答题 → 授权 → 心跳扣减；
  6. 家长改每日上限，TV 30s 内生效；
  7. 制造 BLOCKED（答题失败），家长远程解锁 → TV ≤10s 恢复；
  8. 解绑设备 → TV 进入未激活；
  9. 查看周报。

## 5. 回滚方案

- 触发条件：远程解锁被滥用或迁移异常；
- 服务端：关闭解锁路由开关（配置项）→ 回滚迁移（先确认无 parent 授权数据）；
- 客户端：保留上一版 APK；远程解锁入口可远程配置隐藏（P1）；
- 数据：`watch_grant.source='parent'` 可批量置为 revoked。
