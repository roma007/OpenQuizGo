## 1. 范围

- 服务端：覆盖率聚合接口与测试；
- 管理端 Web：登录、题目列表/编辑/工作流、导入、审计、覆盖率；
- 不包含：难度校准算法、题目图片上传、移动端、独立部署流水线。
