## 1. 目标与范围

- 交付目标：孩子端（电视 + 平板）与家长端 Android 统一使用 `docs/brand/` 官方 logo；孩子端补 Android TV banner。
- 不包含：应用内 logo、应用名、iOS 图标、主题图标（monochrome）。

## 3. 关键实现约定

1. 图标源只使用 `docs/brand/logo-1024.png`，不引入新的母版或第三方图标库。
2. 自适应图标背景层使用「整张 logo 缩至 96% 居中 + 底板色补齐」，前景层为透明 PNG。
3. banner 为 320×180 不透明 PNG，左侧 logo、右侧两行文字；文字不依赖远程字体。
4. 不改包名、版本号、权限、接口和页面代码。
5. 资源生成后需在平板上实际安装验证；仅看文件尺寸不算验收。

## 4. 验证方式

| 层 | 方式 |
| --- | --- |
| 资源 | 检查各密度尺寸、banner 320×180、透明前景层 |
| 构建 | `cd tv && ./gradlew assembleDebug --offline`；`cd parent && flutter build apk --debug` |
| 平板 | 安装两端 APK，打开应用抽屉截图，确认图标为官方亲子 logo |
| 电视 | `aapt dump badging` 确认 `banner`/`icon` 声明；有条件时在 `tvhome-tv` 模拟器复查 Leanback 图块 |
| 回归 | 包名、版本号、登录与主页功能不受影响 |
