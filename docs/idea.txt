
## 四、功能需求

### 4.1 答题解锁机制

- 观看前 / 观看中答题，答对达阈值解锁观看时长
- 规则引擎支持：观看时长、答题通过阈值、时段限制（如晚 8 点后不可看）、按学科设不同权重阈值
- **断网降级**：允许看已缓存内容限时（默认 10 分钟）；**核心规则校验与答案判定不落本地，必须走服务端**

### 4.2 学科体系（三层结构 + 趣味类目）

- **核心学科**：数学思维（主力）、语文素养、英语启蒙
- **素养学科**：科学常识、逻辑推理、生活 / 安全常识
- **专题内容**：节日题包、IP 联动题包、寒暑假专题（运营抓手，不占学科框架）
- **趣味类目**（脑筋急转弯）：
  - 独立 `category`，**不进学科矩阵考核**
  - 学段只分两档：3–8 / 9+
  - 题型以选择 + 语音为主
  - 必须标准答案 + 近义答案白名单
  - 设占比上限：一次解锁最多 1–2 道
  - 家长可开关
- **底层一套题库，学科只是标签**；禁止按学科拆独立模块 / 独立表

### 4.3 学段与年级

- **学段刚性四档**（必填，题库按学段铺满）：

| 学段 | 对应年级参考 | 题型重心 |
|---|---|---|
| 启蒙 3–5 | 幼儿园小 / 中 / 大班 | 图、音、连线、选择 |
| 低年级 6–8 | 一~三年级 | 图文选择、简单填空、排序 |
| 中年级 9–11 | 四~六年级 | 文字题干、多步推理、阅读 |
| 高年级 12+ | 初一及以上 | 短平快学科题、逻辑题 |

- **年级柔性**：`grade_tag` 选填，不单独建题库，仅在学段题池内做难度偏移 / 推荐加权
- 家长默认选学段，「精准模式」可选年级；映射为默认推荐，家长可覆盖
- **不做 12 年级硬分层**

### 4.4 题库治理（完整版重点）

- 后台按 `学科 / 学段 / 难度 / 题型` 四维检索、批量导入、版本管理、上下架
- **难度校准**：用真实正确率反推（>90% 降难度，<40% 升难度）
- **质量审核流**：教研出题 → 审核 → 试答 → 上线，多角色权限
- **覆盖率看板**：`学科 × 学段 × 难度` 热力图，防断供；`grade_tag` 只做分布统计，不纳入铺满考核
- **推荐引擎**：按学段筛池 → 按 grade_tag 加权 → 按历史正确率动态调难度与学科配比
- **A/B 测试**能力

### 4.5 运营与变现

- 基础学科免费；素养学科 / 专题题包做会员或单购
- 每日一题、节日题包、亲子对战（挂趣味类目）
- 会员订阅体系

## 五、数据与架构

### 5.1 服务端（必须做）

服务端是产品「大脑」，承载四件事：**题库、规则引擎、账号家庭体系、数据报告**。

- 早期可用 BaaS（Supabase / Firebase / LeanCloud）覆盖账号、数据库、推送；用户量起来再迁自建
- 客户端薄，**规则判定与答案校验走服务端接口**
- 接口设计预留扩展：题型 `type`（选择 / 语音 / 看图 / 填空 / 排序 / 连线）、`ageRange`、`difficulty` 等字段

### 5.2 核心数据模型（字段清单）

#### `question`（题目主表）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | bigint/uuid | 是 | 主键 |
| `subject` | enum | 是 | 学科标签：math / chinese / english / science / logic / safety / fun |
| `category` | enum | 是 | 类目：core / literacy / topic / fun |
| `stage` | enum | 是 | 学段：preschool / low / mid / high |
| `grade_tag` | enum/null | 否 | 年级微调标签 g1~g9，仅学段内偏移 |
| `difficulty` | tinyint | 是 | 难度 1–5，可被正确率反推校准 |
| `type` | enum | 是 | choice / voice / image / fill / sort / match |
| `stem` | text | 是 | 题干 |
| `stem_media` | json | 否 | 题干图 / 音资源（低龄必填） |
| `options` | json | 条件 | 选项（选择题必填） |
| `answer` | json | 是 | 标准答案（选项 id / 文本 / 排序序列） |
| `answer_alias` | json | 否 | 近义答案白名单（趣味题必填） |
| `explain` | text | 否 | 解析 |
| `duration_limit` | int | 否 | 单题限时秒数（学科 ≤30，趣味 10–20） |
| `topic_id` | bigint | 否 | 归属专题题包 |
| `status` | enum | 是 | draft / review / trial / online / offline |
| `version` | int | 是 | 版本号 |
| `schema_ver` | int | 是 | json 字段 schema 版本 |
| `created_by` / `reviewed_by` | bigint | 是 | 教研 / 审核角色 |
| `created_at` / `updated_at` | datetime | 是 | 时间戳 |

#### `tag_dict`（标签字典）

- `tag_type`：subject / category / stage / grade / difficulty / type
- `tag_value`、`tag_name`、`sort`、`enabled`
- **新增学科 / 题型只加字典值，不改表结构**

#### `topic_pack`（专题题包）

- `id`、`name`、`type`（节日 / IP / 假期 / 每日一题）、`subject_scope`、`stage_scope`、`start_at` / `end_at`、`is_paid`、`status`

#### `watch_rule`（规则配置，独立于题库）

| 字段 | 说明 |
|---|---|
| `id` / `child_id` | 规则归属孩子档案 |
| `unlock_minutes` | 每次解锁观看时长 |
| `pass_threshold` | 答对题数阈值 |
| `subject_weight` | json，按学科设不同权重阈值 |
| `fun_ratio_cap` | 趣味题占比上限（如 1–2 道/次） |
| `fun_enabled` | 家长开关 |
| `time_window` | 允许观看时段 |
| `daily_limit` | 每日总时长 |
| `offline_fallback_min` | 断网降级分钟数（默认 10） |
| `updated_by` / `updated_at` | 家长修改留痕，实时下发电视端 |

#### `answer_log`（答题记录）

- `id`、`child_id`、`question_id`、`device_id`、`answer_given`、`is_correct`、`duration_ms`、`answered_at`
- 用途：难度校准、成长报告、推荐引擎

#### `watch_log`（观看记录）

- `id`、`child_id`、`device_id`、`start_at`、`end_at`、`unlocked_by`（关联答题会话）、`content_id`

#### 家庭与账号

- `family`（id、家长账号、会员状态）
- `child_profile`（id、family_id、昵称、生日 → 自动映射学段、当前 stage / grade_tag、头像）
- `device_bind`（device_id、child_id、端类型 tv / phone / pad / miniapp、绑定状态）
- `family_member`（family_id、家长账号、角色、二次验证状态）

#### 覆盖率看板视图

- 维度：`subject × stage × difficulty` 在线题数
- 阈值告警：某格子低于 N 题即预警断供
- `grade_tag` 单独分布统计，不纳入铺满考核

#### `growth_report`（报告聚合）

- `child_id`、`period`（周 / 月）、`subject_stats`（json：正确率 / 题量 / 趋势）、`fun_stats`（单列，不计学科）、`watch_minutes`、`generated_at`

#### 扩展预留

- `question.type` 新增题型只加枚举 + 渲染器，不改表
- `subject` 新增学科只加字典值
- 所有 json 字段（options / answer / rule）带 `schema_ver`，便于迁移

## 六、非功能要求

- **合规**：儿童个人信息保护，数据最小化、家长同意、加密存储；学科表述避开培训口径
- **体验**：电视端遥控器可达、大字体、语音答题；单题时长控制（学科 ≤30 秒，趣味 10–20 秒）
- **防绕过**：规则与答案校验不落本地
- **多端同步**：手机规则、电视执行记录、平板答题数据汇总一处
- **内容审核**：儿童向，禁止低俗 / 歧义 / 硬凑谐音题

## 七、分期建议（完整版内部排序）

| 期 | 内容 |
|---|---|
| 1 | 服务端 + 题库数据模型 + 标签体系 + 规则引擎 |
| 2 | **Android TV 电视端 + 家长端手机 App（设置 / 报告）**（同期上线） |
| 3 | 题库治理后台 + 覆盖率看板 + 难度校准 |
| 4 | 平板端、小程序、孩子端互动 |
| 5 | 运营层：专题题包、每日一题、亲子对战、会员体系 |
| 6 | 推荐引擎与 A/B |

## 八、硬约束（务必遵守）

1. 学科是**标签**不是模块，禁止按学科拆表 / 拆服务
2. 学段必填且铺满，年级选填只做偏移，**不做 12 年级硬分层**
3. 脑筋急转弯是**独立趣味类目**，不进学科矩阵、设占比上限、答案白名单、家长可关
4. 电视端薄客户端，规则与判分在服务端
5. **家长端必做**：装家长手机、强身份验证、推送、离线可看、多家长家庭组
6. 面向儿童，合规与内容审核前置，不后补
7. 所有扩展点（题型 / 学科 / 学段）用标签 / 枚举预留，避免后期重构
