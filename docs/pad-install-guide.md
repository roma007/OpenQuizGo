# 安卓平板安装指南

> 面向家长，不涉及技术名词。电视端的安装方式不变，本文只讲平板。
> 实现见 [设计 084](design/084-安卓平板守护端.md)。

## 一、装之前要知道的三件事

1. **同一个安装包**：电视和平板用的是同一个 App，界面会自动变成适合手指点的样子。
2. **只有安卓平板可以**：iPad 不行（苹果系统不允许这类管控），iPad 只能用苹果自带的「屏幕使用时间」。
3. **平板必须能连到我们的服务端**：现在服务端走内网（Tailscale）。平板要么也装 Tailscale 并登录同一个账号，要么让管理员把平板加入白名单。

## 二、安装（约 3 分钟）

1. 把 `app-release.apk` 传到平板（微信文件传输 / 数据线 / U 盘都行）。
2. 在平板上点开这个文件，允许「安装未知来源应用」。
3. 桌面出现「OpenQuizGo 守护端」图标，点开。
4. 用**家长手机号**收验证码登录。

登录成功后，这台平板会出现在家长端「设备」里，并标记为「平板」。

## 三、必须开的两项权限（缺了不会拦截）

打开 App 后，主页会显示「还差两步才能生效」，照着点：

### 1. 无障碍服务

- 点「去开启无障碍」→ 找到「OpenQuizGo 守护端」→ 打开开关。
- **开关是灰的怎么办（安卓 13 及以上）**：
  设置 → 应用 → OpenQuizGo 守护端 → 右上角三个点 → **允许受限设置** → 再回来打开无障碍。

### 2. 使用情况统计

- 点「去开启使用情况」→ 找到「OpenQuizGo 守护端」→ 允许。

两项都变成「✓」后，主页不再提示，说明生效了。

## 四、让它在后台活下来

不同品牌叫法不一样，找类似的开关打开即可：

| 品牌 | 位置 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 守护端 → **自启动** + **省电策略：无限制** |
| 华为 / 荣耀 | 设置 → 应用 → 守护端 → 耗电管理 → **允许后台活动** |
| OPPO / 一加 | 设置 → 电池 → 应用耗电管理 → 守护端 → **允许后台运行** |
| vivo | 设置 → 电池 → 后台耗电管理 → 守护端 → **允许后台高耗电** |
| 三星 | 设置 → 电池 → 后台使用限制 → 把守护端加入「永不进入休眠」 |

另外：不要在多任务里把守护端划掉，划掉后拦截会失效。

## 五、验证是否真的生效

1. 让孩子用的视频 App（爱奇艺、腾讯视频、优酷、B 站、芒果、抖音等）随便放一个视频。
2. 到设定的答题时间后，平板应该自动跳出全屏答题页。
3. 答对够题数 → 显示「挑战成功」，获得观看时长；答错 → 显示「休息一下吧」。

如果第 2 步没反应：

- 回到守护端主页，看两项权限是不是还是「✓」；
- 主页「今日已看」如果一直是 0，说明前台识别没生效，多数是「使用情况统计」没开；
- 主页连续点「版本」5 次可进诊断页，能导出日志发给我们。

## 六、家长端能看到什么

- 家长端 → 设备：名称为平板型号，旁边标「平板」。
- 点进去的设置页与电视完全一样：做题间隔、每次题量、答对几题算通过、每日上限、家长 PIN 放行。
- 「临时放行」同样对平板生效，平板 10 秒内恢复。
