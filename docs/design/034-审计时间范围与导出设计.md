## 1. 目标

审计日志支持时间范围筛选并导出 CSV：

- `from` / `to`（YYYY-MM-DD，含首尾日期）；
- 与其他过滤条件组合；
- 导出当前筛选结果为 CSV。

## 2. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/admin/audit` | 增加 `from`、`to` |
| GET | `/v1/admin/audit/export` | 同参数导出 CSV |

- `from`/`to` 使用日期，服务端按 `created_at >= from 00:00`、`< to+1day`；
- 非法日期返回 422；
- CSV 列：id、actor_type、actor_id、action、target_type、target_id、created_at、after_data。

## 3. 前端

- 审计页增加日期范围选择器；
- 「导出 CSV」按钮按当前过滤条件下载；
- 导出文件名 `audit.csv`。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 大数据导出 | 最多 5000 行，超出截断并在文件名/响应头说明 |
| 日期时区 | 按服务端本地时区（与 created_at 一致） |
| CSV 注入 | 对公式前缀做转义 |
