## 1. 目标

家庭排行榜支持 **总榜 / 本周 / 本月**：

- 总榜：全部已完成对局；
- 本周：`finished_at >= date_trunc('week', now())`；
- 本月：`finished_at >= date_trunc('month', now())`；
- 切换周期后重新统计积分、连胜与排名。

## 2. 接口

`GET /v1/family/battles/ranking?period=all|week|month`（默认 `all`）

- 非法 period 返回 422；
- 统计口径不变（胜 3/平 1/负 0，当前/最佳连胜仅基于该周期）。

## 3. 前端

- 排行榜标题右侧 Segmented：总榜 / 本周 / 本月；
- 切换时重新加载排行榜（对战记录不随周期变化）；
- 空态沿用「完成一局后生成排行榜」。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 周期边界时区 | 使用数据库 `date_trunc`，与现有统计一致 |
| 缓存 | 排行榜不缓存，实时查询 |
| 旧客户端 | period 可省略，默认 all |
