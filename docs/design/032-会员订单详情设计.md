## 1. 目标

管理端订单列表增加详情弹窗，集中展示：

- 订单号、套餐、金额、时长、状态、渠道、外部交易号；
- 创建/支付/退款时间；
- 退款原因、操作人；
- 退款前后会员快照（状态、套餐、到期时间）。

服务端已有字段，本期只做前端展示。

## 2. 交互

- 订单表「操作」列增加「详情」按钮（所有状态可用）；
- 弹窗只读，底部关闭；
- 退款快照不存在时显示「—」；
- 退款按钮逻辑保持不变。

## 3. 风险

| 风险 | 对策 |
| --- | --- |
| 快照字段缺失 | 空值显示占位 |
| 操作人 UUID 不易读 | 显示 ID + 复制 |
| 信息过多 | Descriptions 两列布局 |

## 4. 后续

- 订单对账/发票入口；
- 快照对比高亮变化。
