## 1. 目标

在家长端对战页面展示家庭内孩子的对战排名：

- 每名孩子：场次、胜/平/负、积分（胜 3、平 1）、当前连胜、最佳连胜；
- 按积分、胜场排序；
- 高亮当前孩子；
- 只有已完成对局计入。

## 2. 接口

`GET /v1/family/battles/ranking`（家长令牌）

```json
{"items":[
  {"child_id":"...","child_name":"小明","battles":5,"wins":3,"draws":1,
   "losses":1,"points":10,"current_streak":1,"best_streak":2}
]}
```

- 家庭范围取当前账号的 active family；
- 无对局的孩子也返回，数据为 0；
- 排序：积分降序 → 胜场降序 → 名字升序。

## 3. 规则

- 胜：`child_score > parent_score`；
- 平：相等；
- 负：小于；
- 当前连胜：最近连续获胜场次；
- 最佳连胜：历史最长连续获胜。

## 4. 前端

- 对战入口新增「家庭排行榜」卡片，展示排名、孩子、积分、胜/平/负、当前连胜；
- 当前孩子高亮；
- 空数据提示「完成一局后生成排行榜」；
- 与对战记录并列，刷新时一起更新。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 家庭孩子多、对局多 | 只统计 finished；单家庭数据量有限 |
| 排序不稳定 | 积分→胜场→名字 |
| 隐私 | 仅返回家庭内昵称，不含账号 |
