## 1. 背景与目标

- 086 已让 `https://quiz.openapp.asia` 公网可用（`1.0.56`），证书为 DigiCert DV，链路可信。
- 但两端客户端的**默认**服务端地址仍是指向备案前的临时通道：

| 客户端 | 文件 | 当前默认值 | 问题 |
| --- | --- | --- | --- |
| 家长端（Flutter） | `parent/lib/core/config.dart` | `http://127.0.0.1:8080/` | 不传 `--dart-define` 就指向手机自身，装到真机必然连不上 |
| 电视端（Android） | `tv/app/build.gradle.kts` | `http://100.65.110.80:8082/` | **明文 HTTP**；`targetSdk 33` 下 release 包默认禁止明文，只有 debug 包能用（`tv/app/src/debug/AndroidManifest.xml` 开了 `usesCleartextTraffic`） |

目标：**默认构建即指向 `https://quiz.openapp.asia/`**，本地联调仍可用构建参数覆盖。

## 2. 需求与验收标准

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| R1 | 家长端默认 `https://quiz.openapp.asia/` | `dart analyze lib test` 通过；`flutter run` 不带 `--dart-define` 时连生产 |
| R2 | 电视端默认 `https://quiz.openapp.asia/` | `assembleRelease` 产物内 `BuildConfig.API_BASE_URL` 为 https；装机后 `/v1/meta` 请求成功 |
| R3 | 本地联调不被破坏 | 家长端 `--dart-define=API_BASE_URL=http://10.0.2.2:8089/`、TV `-PapiBaseUrl=http://…` 仍生效 |
| R4 | 明文依赖收窄 | release 包不再依赖 `usesCleartextTraffic`；debug 包保留 |
| R5 | 文档与部署清单同步 | `tv/README.md`、`parent/README.md`、`docs/deployment-todo.md` 一致 |

## 3. 方案对比与选型

| 方案 | 做法 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- | --- |
| A 改默认值，保留构建参数覆盖 | 两个默认常量改成生产域名 | 改动最小、一条命令回退、无新概念 | 本地开发必须显式传参（现在也要传，等于是把「默认」从错的改对） | **选 A** |
| B 加 dev/prod flavor | Gradle productFlavors / Flutter flavors | 显式区分环境 | 双份构建配置、签名与包名要跟着分叉，收益不足以抵成本 | 否 |
| C 运行时下发配置 | 启动先请求一个固定引导域名取配置 | 换域名不用发版 | 仍需要一个引导域名（绕圈）；首启多一次网络依赖，弱网体验差 | 否 |

## 4. 总体设计

- **家长端**：`AppConfig.apiBaseUrl` 默认改为 `https://quiz.openapp.asia/`；本地调试一律用 `--dart-define`（README 已这么写）。
  iOS 的 ATS 只开了 `NSAllowsLocalNetworking`，公网 https 不受影响；Android release 无 `usesCleartextTraffic`，正好匹配。
- **电视端**：`build.gradle.kts` 的 `apiBaseUrl` 默认改为 `https://quiz.openapp.asia/`，注释保留 Tailscale 覆盖方式
  （`-PapiBaseUrl=http://100.65.110.80:8082/`，仅 debug 包可用，因为 release 禁明文）。
- **不做**：不做证书 pinning（DigiCert 轮换会锁死客户端）、不做域名兜底重试（多域名会把备案范围搞复杂）。

## 5. 数据模型与接口

无变化。仅客户端 baseUrl 常量。

## 6. 非功能要求

- 兼容性：`minSdk 26` / iOS 13+ 均信任 DigiCert 公共根，无需额外配置。
- 可观测：TV 首页与平板页已显示「服务端：${API_BASE_URL}」，装错包一眼可见。
- 安全：release 包不再走明文；`8082` 明文口仅留 tailnet 排障，不进客户端默认值。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 存量包仍指向 Tailscale IP | 老包在非 tailnet 网络下不可用 | 本次发版即升级；老包不做兼容（内部用户） |
| 用户设备时间错乱导致证书校验失败 | 登录失败 | 错误文案已有网络类提示；必要时引导校准时间 |
| 证书 2027-02-21 到期未换 | 全端不可用 | 见 086 T11 续期排期 + `status.sh` <14 天 ⏳ |
| 家长端开发者忘记 `--dart-define` | 本地连到生产库 | README/计划都写清；生产账号无测试数据权限 |
