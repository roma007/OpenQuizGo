## 1. 目标

按天记录题库总量与各状态数量，形成覆盖率趋势，帮助运营观察题库增长与上线节奏。

## 2. 数据

新增 `coverage_snapshot`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `captured_on` | date PK | 快照日期 |
| `total` | int | 题目总量 |
| `online` | int | 已上线 |
| `draft` | int | 草稿 |
| `in_review` | int | 待审核 |
| `offline` | int | 已下线 |
| `created_at` | timestamptz | 首次写入 |

同一天重复采集使用 UPSERT 覆盖，保留最新值。

## 3. 接口

- `POST /v1/admin/coverage/snapshot`（`question.write`）：采集/刷新今日快照；
- `GET /v1/admin/coverage/trend?days=30`（`question.read`）：返回按日期升序的快照。

worker 每次报告周期顺便采集一次今日快照，实现自动趋势。

## 4. 管理端

覆盖率页新增「覆盖率趋势」卡片：

- 展示最近 30 天总量与上线数；
- 横向条形对比；
- 「记录今日快照」按钮，便于立即生成。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 同日重复写入 | 主键 UPSERT |
| 历史缺失 | 从上线后开始积累，不伪造数据 |
| 时区差异 | 使用数据库 `current_date` |
