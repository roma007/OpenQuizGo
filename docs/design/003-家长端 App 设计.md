## 1. 背景与目标

### 1.1 现状

- 服务端已完成：登录、家庭/孩子、规则、设备激活/解绑、报告、答题与授权计量。
- TV 守护端 v0.2.0 已实机验收：答题解锁、心跳计量、阻挡页、家长解锁**等待页**（轮询新授权）。
- 目前家长只能通过接口/数据库操作，缺少可用手机端；电视端「家长解锁」尚无签发入口。

### 1.2 本次目标

交付家长端 App MVP（Android APK + iOS 可构建），覆盖：

1. 手机号验证码登录、令牌自动刷新、退出登录；
2. 家庭与孩子档案管理；
3. 电视设备激活绑定、解绑、设备列表；
4. 观看规则配置（预设 + 进阶），保存前 dry-run，PIN 二次确认；
5. 周/月成长报告；
6. **远程解锁**：家长输入 PIN 为电视签发一段观看时间，电视阻挡页 5s 内自动放行（补齐 TV v0.2.0 的家长解锁闭环）；
7. 家长 PIN 设置/修改、家庭成员邀请。

### 1.3 非目标

- 不做管理端题库维护（已有 CLI/API）。
- 不做推送通知（FCM/APNs）与消息中心，留到下一期。
- 不做 iPad/平板专门布局、深色模式之外的主题定制。
- 不做应用商店上架流程（仅内部测试包）。

## 4. 总体架构

```
┌──────────────────────────────┐
│ Flutter 家长端                │
│  features/                   │
│   auth / family / device /   │
│   rule / report / unlock /   │
│   settings                   │
│  core/ (api, storage, ui)    │
└──────────────┬───────────────┘
               │ HTTPS + JWT
┌──────────────▼───────────────┐
│ Go 服务端（v0.1.0 + 003 增补）│
│  identity / rule / report /  │
│  watch / quiz                │
└──────────────┬───────────────┘
               │
        PostgreSQL / Redis
```

模块职责：

- `core/api`：dio、token 拦截器、401 自动刷新、错误码到中文提示；
- `core/storage`：安全令牌、离线缓存（孩子/规则/报告 JSON + 时间戳）；
- `features/auth`：登录、验证码倒计时、退出；
- `features/family`：孩子列表/编辑、成员邀请；
- `features/device`：设备列表、激活绑定、解绑、远程解锁；
- `features/rule`：预设/进阶表单、可达性预览、PIN 确认；
- `features/report`：周/月报告图表；
- `features/settings`：PIN、关于、退出。

关键流程（远程解锁）：

```
家长点「临时解锁」→ 输入 PIN 与分钟数
  → POST /v1/family/devices/{deviceID}/unlock
  → 服务端校验家庭/设备/PIN/每日额度
  → 插入 watch_grant(source=parent, session_id=NULL)
  → 返回 Grant
  → 电视阻挡页每 5s GET /watch/grants/active
  → adoptGrant → BLOCKED → GRANTED
```

## 5. 数据模型

家长端不新增本地业务实体，仅缓存服务端视图；服务端需一处迁移：

### 5.1 迁移 00007_parent_unlock.sql

```sql
alter table watch_grant alter column session_id drop not null;
alter table watch_grant add column if not exists source text not null default 'quiz';
alter table watch_grant add constraint watch_grant_source_chk
  check (source in ('quiz', 'parent'));
```

- `source='parent'` 时 `session_id` 为空；
- 现有数据保持 `source='quiz'`；
- 唯一约束 `session_id` 允许多个 NULL（Postgres 默认行为）。

### 5.2 客户端缓存

| Key | 内容 | 失效 |
| --- | --- | --- |
| `children_cache` | 孩子列表 JSON | 5 分钟 / 写操作后刷新 |
| `rule_cache:<childID>` | 规则 + 版本 | 5 分钟 |
| `report_cache:<childID>:<period>` | 报告 JSON | 10 分钟 |

## 6. 接口设计

### 6.1 复用现有接口

| 类型 | 名称 | 说明 |
| --- | --- | --- |
| POST | `/v1/auth/sms/code` | 发送验证码（dev 固定 123456） |
| POST | `/v1/auth/login` | 登录，返回 access/refresh token |
| POST | `/v1/auth/refresh` | 刷新令牌 |
| POST | `/v1/auth/logout` | 退出 |
| GET | `/v1/family/me` | 当前账号/家庭 |
| GET/POST | `/v1/family/children` | 孩子列表/新增 |
| GET/PUT | `/v1/family/children/{id}` | 孩子详情/修改 |
| GET/PUT | `/v1/family/children/{id}/rule` | 规则读取/更新（PUT 需 PIN） |
| POST | `/v1/family/children/{id}/rule/preview` | 规则 dry-run |
| GET | `/v1/family/children/{id}/reports` | 周/月报告 |
| GET | `/v1/family/devices` | 设备列表 |
| POST | `/v1/family/devices/activate` | 激活码绑定 |
| DELETE | `/v1/family/devices/{id}` | 解绑 |
| POST | `/v1/family/pin` | 设置/修改 PIN |
| POST | `/v1/family/pin/verify` | 校验 PIN |
| POST | `/v1/family/members/invite` | 邀请码 |
| POST | `/v1/family/members/join` | 加入家庭 |

### 6.2 新增接口（003 服务端增补）

| 类型 | 名称 | 入参 | 出参 | 说明 |
| --- | --- | --- | --- | --- |
| POST | `/v1/family/devices/{deviceID}/unlock` | `{pin, minutes}` | `Grant` | 家长远程解锁；校验 PIN/设备归属/每日额度；忽略时段限制；限流 3 次/小时/设备 |

约定：

- `minutes` 范围 5–60，默认 `offline_fallback_min`（10）；
- 签发受 `daily_limit` 约束，额度不足返回 `403 RULE_DAILY_LIMIT`；
- PIN 错误返回 `403 PIN_INVALID`；设备不属于本家庭 `404 DEVICE_NOT_FOUND`；
- 每次解锁写入 `audit_log`（actor=account, action=`device.unlock`, target=deviceID）；
- 返回与 `/watch/grants/active` 相同的 `Grant` 结构，电视端无需改动。

### 6.3 报告出参（现有）

`period`、`period_start/end`、`subject_stats{answered,correct,accuracy}`、`fun_stats`、`watch_minutes`、`generated_at`。

## 7. 非功能要求

- 性能：首屏 ≤2s（缓存命中 ≤500ms）；列表滚动 60fps；
- 安全：token 仅存 Keychain/Keystore；日志不打印 token/PIN；PIN 错误锁定由服务端保证；
- 可观测：统一错误上报（可选 Sentry，MVP 先本地日志）；
- 兼容：Android 7+、iOS 13+；刘海屏/横屏安全区；
- 可维护：feature-first 目录；API 模型集中；新增接口补 widget/unit test。

## 8. 风险与对策

| 风险 | 影响 | 概率 | 对策 |
| --- | --- | --- | --- |
| 远程解锁绕过时段限制被滥用 | 规则失效 | 中 | PIN + 每日额度 + 限流 + 审计；后续加家长端二次确认 |
| Flutter 环境/iOS 构建缺失 | 无法出 iOS 包 | 高 | 先交付 Android APK；iOS 提供可构建工程与说明 |
| 报告数据为空（新家庭） | 页面空白 | 高 | 空态文案与引导答题 |
| 规则配置不可达 | 孩子永远无法解锁 | 中 | 保存前 preview + 预设档位 |
| 设备离线时远程解锁无效 | 家长困惑 | 中 | 解锁页提示「电视需联网，最多 10 秒生效」 |
| 激活码过期/已被使用 | 绑定失败 | 中 | 错误提示 + 重新生成指引 |
