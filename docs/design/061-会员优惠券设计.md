## 1. 目标

支持固定金额优惠券：管理端创建/停用，家长下单时使用，订单记录原价、优惠与实付；退款时归还使用次数。

## 2. 数据

`membership_coupon`：

| 字段 | 说明 |
| --- | --- |
| `code` | 唯一，大写字母数字 4–32 |
| `name` | 名称 |
| `amount_cents` | 固定优惠金额（分） |
| `min_amount_cents` | 最低订单金额 |
| `starts_at/expires_at` | 可选有效期 |
| `max_uses` | 0 表示不限 |
| `used_count` | 已使用次数 |
| `status` | active/disabled |

`membership_order` 增加 `original_amount_cents`、`discount_cents`、`coupon_code`。

## 3. 接口

- 管理端：`GET/POST /admin/membership/coupons`、`PUT /admin/membership/coupons/{id}`；
- 家长端：`POST /family/membership/coupons/validate` body `{code, plan_id}`；
- 创建订单 body 增加可选 `coupon_code`；
- 订单响应增加原价/优惠/优惠码。

## 4. 规则

- 优惠金额不超过套餐价；
- 校验状态、有效期、最低金额、使用次数；
- 下单事务内锁定优惠券并 `used_count+1`；
- 退款成功时若订单使用优惠券则 `used_count-1`（不低于 0）。

## 5. 管理端/家长端

- 管理端新增「优惠券」页面：列表、创建、启用/停用；
- 家长端支付对话框支持输入优惠码，显示实付金额。

## 6. 风险

| 风险 | 对策 |
| --- | --- |
| 并发超用 | 行锁 + used_count 校验 |
| 优惠为负 | clamp 到 0–套餐价 |
| 退款后重复用 | 退款归还次数 |
