## 1. 目标

TV 诊断页可把本地日志上传到服务端，支持远程排障，无需家长手动分享文件。

## 2. 数据

新增 `device_diagnostic`：

| 字段 | 说明 |
| --- | --- |
| `id` | bigserial |
| `device_id` | 设备 ID |
| `child_id` | 孩子 ID |
| `content` | 日志文本，最多 256KB |
| `bytes` | 字节数 |
| `note` | 可选备注 |
| `created_at` | 上传时间 |

索引 `(device_id, created_at desc)`。

## 3. 接口

- 设备：`POST /v1/device/diagnostics`，设备令牌鉴权，body `{content,note}`；
- 管理端：`GET /v1/admin/diagnostics?device_id=&limit=20`（`family.read`）；
- 管理端：`GET /v1/admin/diagnostics/{id}` 返回详情。

限制：content 1–256KB；设备只能上传自己的日志；管理端只读。

## 4. TV

- 诊断页新增「上传诊断」按钮；
- 合并 `guard.log.1` + `guard.log` 后上传；
- 成功后提示，失败写入本地日志并提示；
- 不记录令牌/密钥。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 日志过大 | 256KB 上限，超出截断 |
| 敏感信息 | 沿用 049 隐私约束 |
| 重复上传 | 允许，管理端按时间排序 |

## 6. 后续
