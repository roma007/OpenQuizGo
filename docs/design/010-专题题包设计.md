## 1. 目标

第 5 期「专题题包」第一步：教研可创建专题包、选择题目、上下线，供后续专题/假期/每日活动使用。

- 使用已有 `topic_pack` / `topic_question` 表；
- 不改变现有组卷逻辑（专题包接入组卷留到后续）。

## 2. 模型

`topic_pack`：name、type（holiday/ip/vacation/daily）、subject_scope、stage_scope、start_at/end_at、is_paid、status（draft/online/offline）。

`topic_question`：topic_id、question_id、position。

## 3. 接口（管理员）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/admin/topics` | 列表（含题目数） |
| GET | `/v1/admin/topics/{id}` | 详情 + question_ids |
| POST | `/v1/admin/topics` | 新建 |
| PUT | `/v1/admin/topics/{id}` | 修改元数据/状态 |
| DELETE | `/v1/admin/topics/{id}` | 删除 |
| PUT | `/v1/admin/topics/{id}/questions` | 全量设置题目 `{question_ids:[...]}` |

## 4. 管理端

- 「专题题包」菜单：列表、新建/编辑弹窗（名称/类型/范围/时间/付费/状态）；
- 选题：搜索题目 → 添加；已选列表可移除；保存全量覆盖；
- 校验：名称必填、类型/状态合法、题目 id 必须存在。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 题目被删除 | 外键级联删除 topic_question |
| 全量覆盖误操作 | 保存前二次确认 |
| 组卷未接入 | 文档标注后续 |
