## 1. 目标

TV 端关键事件（启动、绑定、授权、心跳、错误、答题）写入本地日志文件，家长可在诊断页导出日志用于排障，无需远程服务器。

## 2. 实现

- 新增 `LogStore`：写入应用私有目录 `files/logs/guard.log`；
- 单文件上限 1MB，超出后轮转为 `guard.log.1`（只保留一份）；
- 统一 `GuardLog.i/w/e(tag, message)`，线程安全，失败不影响主流程；
- 诊断页增加「导出日志」按钮，通过 `FileProvider` + `ACTION_SEND` 分享；
- 关键路径埋点：应用启动、激活/绑定、授权刷新、心跳失败、答题提交失败、异常。
- manifest 注册 FileProvider，`res/xml/file_paths.xml` 暴露 logs 目录。

## 3. 隐私

- 不记录令牌、设备密钥、完整家庭信息；
- 日志仅保存在设备私有目录，由家长主动分享；
- 导出文件名为 `openquizgo-tv-log-YYYYMMDD-HHmm.txt`。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 日志无限增长 | 1MB 轮转，仅保留一份 |
| 写日志阻塞主线程 | 同步小写入 + try/catch |
| 分享 URI 权限 | FileProvider + FLAG_GRANT_READ_URI_PERMISSION |
