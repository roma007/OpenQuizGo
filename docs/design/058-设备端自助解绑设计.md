## 1. 背景

TV 端「重置绑定」原先只清除本地令牌，服务端绑定仍为 active，管理端/家庭设备列表会残留旧记录。恢复出厂或卸载后本地令牌丢失，服务端无法主动感知，因此先实现设备在重置前主动通知服务端解绑。

## 2. 目标

- 新增设备鉴权接口 `DELETE /v1/device/me`；
- 服务端将当前设备绑定置为 unbound 并清空令牌；
- TV「重置绑定」先调用接口，再清本地；
- 接口失败不阻塞本地重置（记录日志）。

## 3. 实现

- 设备令牌解析出 device_id；
- `update device_bind set status='unbound', unbound_at=now(), token_hash='', token_expires_at=null where device_id=$1 and status='active'`；
- 返回 200；无 active 绑定返回 404 或幂等 200（选择幂等 200）。

## 4. 安全

| 风险 | 对策 |
| --- | --- |
| 未授权解绑 | 必须设备令牌 |
| 重复调用 | 幂等 |
| 网络失败 | TV 仍清本地，管理端可手动解绑 |

## 5. 限制

- 恢复出厂/卸载后无法自动通知服务端，仍需家长在管理端解绑；
- 不撤销已签发授权（自然过期/心跳失效）。

## 6. 后续

- 管理端批量清理长期离线设备；
- 恢复出厂后的自动解绑（需设备指纹/预置方案）。
