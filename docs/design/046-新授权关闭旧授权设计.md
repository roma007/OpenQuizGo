## 1. 背景

同一孩子同一设备可能同时存在多条 `active` 授权（答题签发与家长解锁并存）。额度校验会把所有 active 授权都计入预留，导致重复占用；TV 端取 active 授权时也可能选到旧记录。

## 2. 目标

签发新授权时，在同一事务内把该孩子 + 该设备的旧 `active` 授权置为 `revoked`，保证同一设备同一孩子最多一条 active 授权。

## 3. 实现

在 `issue`（答题签发）和 `issueParent`（家长解锁）中，插入新授权前执行：

```sql
update watch_grant
set status = 'revoked'
where child_id = $1 and device_id = $2 and status = 'active'
```

- 复用已有 advisory lock，事务内串行；
- 幂等/重放（`session_id` 已存在）直接返回旧授权，不撤销；
- 不影响其他设备或其他孩子的授权；
- 旧授权被撤销后，TV 心跳会收到 revoked，前端提示重新解锁。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 误撤销其他设备 | 限定 child_id + device_id |
| 重放请求撤销新授权 | 先查 session_id 再撤销 |
| 并发签发 | advisory lock + 事务 |
