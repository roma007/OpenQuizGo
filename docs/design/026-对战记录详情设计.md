## 1. 目标

点击对战记录可查看逐题回顾：

- 比分与胜负；
- 每题题干、双方对错、正确答案、解析；
- 未完成对局显示当前状态与比分。

复用现有 `GET /v1/family/children/{childID}/battles/{battleID}`，服务端无改动。

## 2. 前端

- 对战记录卡片可点击（仅已完成/已结束）；
- 新页面 `BattleRecordPage`：加载对局详情；
- 顶部比分卡：模式、日期、比分、胜负；
- 逐题卡片：题干、孩子/家长对错、正确答案、解析；
- 加载失败显示重试；未完成显示「对局尚未结束」。

## 3. 接口

沿用：

`GET /v1/family/children/{childID}/battles/{battleID}`

已完成时返回 `questions`、`answers`、`result`、`scores`。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 记录已不存在 | 404 提示并返回 |
| 未完成对局无 answers | 显示状态而非空白 |
| 题目已下线 | 服务端已有对局题目快照/关联；无答案时显示占位 |
