## 1. 目标

同一实例内多个 SSE 连接订阅同一对局时，只建立一个 Redis 订阅，再本地分发，降低 Redis 连接数。

## 2. 实现

- `eventBroker` 维护 `shared map[battleID]*sharedSubscription`；
- `sharedSubscription`：Redis PubSub、订阅者集合、引用计数；
- 第一个订阅者创建 PubSub 并等待确认；
- 后续订阅者复用；
- 最后一个取消时关闭 PubSub；
- Redis 不可用时仍用进程内总线。

## 3. 风险

| 风险 | 对策 |
| --- | --- |
| 引用计数错误 | 互斥锁 + 单元测试 |
| 订阅确认阻塞 | 首次订阅等待确认 |
| 关闭时漏发 | 广播在锁内快照订阅者 |
