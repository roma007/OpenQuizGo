## 1. 目标

基于现有账号、登录会话、孩子观看与订单数据，提供运营增长/转化/留存视图，不引入埋点 SDK。

## 2. 指标

- 每日：新增账号、活跃账号（有登录会话）、活跃孩子（有观看记录）、支付订单数；
- 转化漏斗：注册账号 → 有孩子 → 有活跃设备 → 有观看记录 → 有支付订单；
- 留存：最近 14 天注册 cohort 的次日/D7 留存（按登录会话判断活跃）。

## 3. 接口

`GET /v1/admin/analytics/growth?days=30`

```json
{
  "days":30,
  "daily":[{"date":"2026-11-05","new_accounts":1,"active_accounts":2,
            "active_children":1,"paid_orders":0}],
  "funnel":{"registered":10,"with_child":8,"with_device":5,"watched":4,"ordered":2},
  "retention":[{"cohort_date":"2026-11-01","new_accounts":3,"d1":2,"d7":1}]
}
```

- `days` 默认 30，最大 90；
- 权限 `dashboard.read`；
- 按数据库日期聚合，不回溯补零以外的数据（每日序列补零）。

## 4. 管理端

新增「增长分析」页面：漏斗卡片、留存表格、每日趋势表/条形图。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 大表查询慢 | 日期范围限制 + 现有索引 |
| 活跃定义有限 | 文档注明仅登录会话/观看 |
| 隐私 | 仅聚合，不返回账号明细 |
