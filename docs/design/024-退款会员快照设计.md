## 1. 目标

退款时保存会员变更前后快照，审计可追溯到期时间与状态变化。

## 2. 数据模型

```sql
alter table membership_order add column refund_before jsonb;
alter table membership_order add column refund_after jsonb;
```

快照内容：

```json
{"status":"active","plan_name":"月度会员","expires_at":"..."}
```

- 无会员记录时 `refund_before = null`；
- 退款后状态可能是 active 或 expired。

## 3. 审计

`after_data` 增加 `before`、`after` 两个对象。

## 4. 接口

订单 JSON 增加 `refund_before` / `refund_after`（omitempty）。

## 5. 测试

- 支付后退款：before 为退款前到期时间，after 为回退后；
- 全额退款后 after.status=expired；
- 重复退款保留原快照。

## 6. 风险

| 风险 | 对策 |
| --- | --- |
| 快照含敏感信息 | 仅套餐/状态/时间，不含账号手机号 |
| 数据体积 | 单订单两个小 JSON |
