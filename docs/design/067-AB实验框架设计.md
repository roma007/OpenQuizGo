## 1. 目标

提供最小可用的 A/B 实验基础设施：

- 管理端创建/停用实验；
- 家长端按 key 获取稳定变体；
- 自动记录首次曝光；
- 管理端查看各变体曝光数。

本期不做指标显著性/自动决策。

## 2. 数据

`experiment(id, key, name, variant_a, variant_b, traffic_percent, status, created_at, updated_at)`。

`experiment_exposure(experiment_id, account_id, variant, first_exposed_at)`，唯一 `(experiment_id, account_id)`。

## 3. 分流

`sha256(key + ":" + accountID)` 前 4 字节转无符号整数 mod 100：

- `< traffic_percent` → variant_b；
- 否则 variant_a；
- 同一账号同一实验稳定不变。

## 4. 接口

- 管理端：`GET/POST /admin/experiments`、`PUT /admin/experiments/{id}`；
- 家长端：`GET /family/experiments/{key}` → `{key,variant,traffic_percent}`，并写曝光（幂等）。

## 5. 管理端

实验列表（key、状态、流量、A/B 曝光数）、创建/编辑弹窗。

## 6. 风险

| 风险 | 对策 |
| --- | --- |
| 分流不稳定 | 哈希账号+key |
| 重复曝光 | 唯一索引 ON CONFLICT |
| 流量越界 | 1–100 校验 |
| 实验冲突 | key 唯一 |
