## 1. 目标

补齐第 3 期「看板可告警」退出条件：

- 覆盖率低于阈值时给出告警；
- 覆盖率数据可导出 CSV，供教研离线分析。

## 2. 规则

- 阈值：同一「学科 + 学段」在线题量 < 50 视为不足（MVP 固定值）；
- 告警文案包含学科、学段、当前题量；
- 导出包含全部聚合单元（学科/学段/题型/状态/难度/题量）。

## 3. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/admin/coverage` | 增加 `warnings: string[]` |
| GET | `/v1/admin/coverage/export` | `text/csv` 下载 |

## 4. 前端

- 覆盖率页顶部显示告警 Alert 列表；
- 「导出 CSV」按钮携带令牌下载。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 阈值不适用 | MVP 固定 50，后续做成规则配置 |
| 大数据导出 | 当前聚合单元 < 1 万，直接生成 |
