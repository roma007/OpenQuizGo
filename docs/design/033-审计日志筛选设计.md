## 1. 目标

管理端审计日志支持按动作、对象类型、操作人、对象 ID 过滤，便于排查题目流转与退款操作。

## 2. 接口

`GET /v1/admin/audit?target_id=&target_type=&action=&actor_id=&limit=`

- 参数均可选，组合为 AND；
- 默认最近 50，最大 200；
- 保持数组响应，兼容现有页面。

## 3. 前端

- 审计页增加：
  - 对象 ID 搜索；
  - 动作 Select（常用动作 + 全部）；
  - 对象类型 Select（question/membership_order）；
  - 操作人 ID 输入；
  - 重置按钮。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| SQL 拼接注入 | 仅使用参数占位与固定字段名 |
| 过滤条件过多 | 全部可选、索引 target/created_at |
