## 1. 目标

在难度校准页查看某题的历史校准记录，并可回滚到之前的难度。

- 历史来源：`audit_log` 的 `question.calibrate`；
- 回滚复用现有 `calibration/apply`，不新增写接口；
- 历史只读。

## 2. 接口

`GET /v1/admin/calibration/history?question_id=&limit=20`

```json
[{"id":1,"question_id":"...","from":1,"to":2,"actor_id":"...","created_at":"..."}]
```

- `question_id` 可选；不传返回最近校准记录；
- 权限 `question.read`；
- limit 默认 20，最大 200。

## 3. 前端

- 校准页每行增加「历史」按钮；
- 弹窗展示 from→to、时间、操作人；
- 每条历史可「回滚到此难度」→ 调用 apply（记录新审计）。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| after_data 缺失 | 跳过或显示 — |
| 回滚覆盖当前 | 二次确认 |
| 历史量大 | limit + 按题目过滤 |
