## 1. 背景与目标

- 服务端已有题目 CRUD、四维检索、导入、审核/上线/下线、RBAC 与审计，但只能通过 curl/脚本操作；
- 第 3 期目标是让教研人员可以独立完成「出题 → 审核 → 上线 → 下线」并查看题库覆盖情况；
- 本次交付 Web 管理端 MVP + 覆盖率接口；难度校准作为 P1（接口与算法未就绪）。

## 2. 需求与验收

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| R1 | 管理员登录 | 账号密码登录；刷新保持登录；无权限菜单隐藏 |
| R2 | 题目列表 | 学科/学段/难度/类型/状态/关键词筛选 + 分页 |
| R3 | 题目详情/编辑 | 新建、编辑 draft/offline；选项编辑器；答案 JSON |
| R4 | 工作流 | 提交审核、通过/驳回、上线、下线、重新提交 |
| R5 | 批量导入 | JSON 数组或 CSV 文本导入，展示成功/失败数 |
| R6 | 审计日志 | 按题目查看操作记录 |
| R7 | 覆盖率 | 按学科/学段/难度/状态聚合，表格热力图 |
| R8 | 权限控制 | 无 `question.publish` 等权限时按钮禁用/隐藏 |

## 3. 方案与选型

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| Vite + React + TS + Ant Design | 组件全、表格/表单快、生态成熟 | 包体较大 | **选用** |
| Vue 3 + Element Plus | 国内资料多 | 团队无既有偏好 | 备选 |
| Go 模板 + HTMX | 无 Node 构建 | 交互/表格能力弱 | 不选 |

- 开发：Vite dev server，`/v1` 代理到 `http://127.0.0.1:8080`（本地 18080），避免 CORS；
- 生产：静态文件由 Nginx 与 API 同源托管（`/admin/` 与 `/v1`），无跨域；
- 登录令牌存 `localStorage`（内部管理端，XSS 风险由同源部署与 CSP 缓解）。

## 4. 页面结构

```
/login                 管理员登录
/                      布局（侧边栏 + 顶栏）
  /questions           题目列表（筛选/分页/批量动作）
  /questions/new       新建题目
  /questions/:id       详情/编辑/工作流/审计
  /import              批量导入
  /audit               审计日志
  /coverage            覆盖率看板
```

## 5. 接口

复用现有：
`POST /v1/admin/auth/login`、`GET /v1/admin/me`、`GET/POST /v1/admin/questions`、`GET/PUT/DELETE /v1/admin/questions/{id}`、`submit-review/review/publish/offline/resubmit`、`POST /v1/admin/questions/import`、`GET /v1/admin/audit`。

新增：
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/admin/coverage` | 聚合 `question`：subject/stage/type/status/difficulty/count + total |

覆盖率响应：
```json
{"cells":[{"subject":"math","stage":"low","type":"choice","status":"online","difficulty":2,"count":120}],"total":2002}
```

## 6. 权限

`/admin/me` 返回角色与权限列表；前端按权限控制：
- `question.read` 查看；
- `question.write` 新建/编辑/提交；
- `question.review` 审核；
- `question.publish` 上线/下线；
- `question.import` 导入；
- `audit.read` 审计。

## 7. 非功能

- 桌面端 ≥1280px；不做移动端；
- 列表分页 20 条；筛选变化重置 offset；
- 导入限制 5MB / 2000 条；
- 所有写操作由服务端审计；前端仅做提示。

## 8. 风险

| 风险 | 对策 |
| --- | --- |
| 令牌 XSS | 同源部署、CSP、短期令牌；后续改 HttpOnly Cookie |
| 大题库表格性能 | 服务端分页，不前端全量加载 |
| 覆盖率查询慢 | 单表聚合 + 索引；必要时缓存 |
| 难度校准未实现 | 本期标注 P1，先交付覆盖率 |
