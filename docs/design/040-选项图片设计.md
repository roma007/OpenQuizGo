## 1. 目标

支持选项图片（单选/看图题）：

- 选项对象增加可选 `image` URL；
- 管理端每个选项可上传/预览/移除图片；
- TV 答题页选项显示图片 + 文案；
- 复用已有 `/v1/admin/media` 与 `RemoteImage`。

## 2. 数据

选项 JSON：

```json
{"id":"a","text":"5","image":"/v1/media/xxx.png"}
```

服务端继续存储 raw JSON，无需迁移。

## 3. 前端

- 管理端 `OptionItem` 增加 `image?`；
- 选项行增加上传按钮、缩略图、移除；
- 保存时保留 `image`，允许纯图片选项（text 可为空）；
- TV `QuizOption` 增加 `image`，选项按钮内渲染图片（最大高度 100dp）。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 纯图片选项无文字 | 校验 id + (text 或 image) |
| 图片过大 | 复用上传大小限制与显示高度 |
| URL 相对路径 | 统一 resolve 拼接 API 基址 |

## 5. 后续

- 多图/选项音频；
- 图片裁剪/压缩；
- 选项图片无障碍描述。
