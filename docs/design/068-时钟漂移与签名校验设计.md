## 1. 背景

篡改类型中 `clock_skew` 与 `package_tampered` 可在客户端本地检测；`uninstall_attempt` 无法在卸载时由自身 App 上报，需 Device Owner/系统权限，单独保留。

## 2. 时钟漂移

- 心跳响应已包含 `server_time`；
- 客户端比较本地时间，偏差 >5 分钟上报 `clock_skew`；
- 详情含 `delta_seconds`；
- 最多每小时上报一次，避免刷量。

## 3. 签名校验

- Gradle 支持 `-PexpectedSignature=<sha256>` 注入 `BuildConfig.EXPECTED_SIGNATURE`；
- 未配置时跳过（debug/内部验收）；
- 启动后计算当前 APK 签名证书 SHA-256（API 28+ `signingInfo`，旧版 `signatures`）；
- 与期望值不一致时上报 `package_tampered`；
- 只上报一次。

## 4. 限制

- 卸载尝试无法由自身 App 感知；
- 签名 pin 需在正式构建流程配置；
- 不影响主流程，上报失败仅记日志。

## 5. 后续

- Device Owner 卸载拦截；
- 签名/版本基线服务端下发；
- 时钟漂移自动纠正提示。
