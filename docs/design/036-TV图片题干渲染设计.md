## 1. 目标

TV 答题页渲染服务端下发的 `stem_media.url`：

- 服务端会话已包含 `stem_media`，客户端补齐模型与展示；
- 相对 `/v1/media/...` 与绝对 URL 都支持；
- 加载失败显示提示，不阻塞答题。

## 2. 实现

- `SessionQuestion` 增加 `stem_media: {url}`；
- 图片 URL：绝对 URL 直接使用，否则 `BuildConfig.API_BASE_URL + path`；
- Compose `RemoteImage`：IO 线程下载 → Bitmap → Image；
- 最大高度 240dp，`ContentScale.Fit`；
- 加载中/失败文案。

## 3. 风险

| 风险 | 对策 |
| --- | --- |
| 图片过大/内存 | 最大高度限制；后续加采样/缓存 |
| 无网络 | 显示加载失败，题干与选项仍可答 |
| 相对 URL 拼接错误 | 统一 `trimEnd('/') + path` |
| 无 TV 设备 | 编译/构建通过；真机待补 |
