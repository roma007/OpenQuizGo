## 1. 目标

选项支持可选音频，用于听音选图/听音选词等题型：

- 选项 JSON 增加 `audio` URL；
- 管理端可上传、试听、移除选项音频；
- TV 每个选项提供独立「播放音频」按钮，再选择答案；
- 复用现有媒体上传与存储，不新增表。

## 2. 媒体

`POST /v1/admin/media` 扩展支持：

| 格式 | 扩展名 | Content-Type |
| --- | --- | --- |
| MP3 | `.mp3` | `audio/mpeg` |
| WAV | `.wav` | `audio/wav` |
| M4A | `.m4a` | `audio/mp4` |
| OGG | `.ogg` | `audio/ogg` |

- 依据文件头识别（ID3/帧同步、RIFF+WAVE、ftyp、OggS），不信任文件名；
- 继续使用现有大小上限（默认 5MB）；
- 图片格式与行为不变。

## 3. 数据与校验

```json
{"id":"a","text":"","audio":"/v1/media/xxx.mp3","images":["/v1/media/a.png"]}
```

- `audio` 可选，非空时必须为去空格后的非空字符串；
- `text`、`image`、`images`、`audio` 至少一个；
- 无迁移，继续存储 raw JSON。

## 4. 管理端

- `OptionItem` 增加 `audio?`；
- 选项卡片增加「上传音频」「试听」「移除音频」；
- 保存时写入 `audio`，空值不写。

## 5. TV

- `QuizOption` 增加 `audio`；
- 选项区域结构：音频播放按钮（如有）+ 选择按钮（图片/文字）；
- 使用 `MediaPlayer` 异步准备播放；切换/离开页面释放；
- 不自动播放，避免多个选项同时发声。

## 6. 风险

| 风险 | 对策 |
| --- | --- |
| 伪造扩展名 | 文件头识别 |
| 多音频同时播放 | 单例播放器，切换时释放 |
| 音频过大 | 沿用上传上限 |
| 电视无解码器 | 失败提示，不影响选择 |
