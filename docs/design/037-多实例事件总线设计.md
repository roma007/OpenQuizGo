## 1. 目标

SSE 事件总线支持多实例部署：任一实例的 Join/Submit 通过 Redis Pub/Sub 通知所有实例上的 SSE 连接。

- Redis 可用时使用 Pub/Sub；
- Redis 不可用/未配置时回退进程内总线；
- 不改变 SSE 协议与客户端。

## 2. 实现

- `eventBroker` 持有可选 `*redis.Client`；
- `publish`：Redis `PUBLISH battle:events:<id>`，失败回退本地；
- `subscribe`：Redis `SUBSCRIBE` 并等待确认，消息转发到本地 channel；
- SSE 连接断开/取消时关闭订阅；
- `battle.New(pool, rdb)`，测试可传 nil。

## 3. 频道

`battle:events:<battleID>`

消息体仅作为唤醒信号（`"1"`），客户端收到后重新拉取状态。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| Redis 故障 | 回退本地总线，单实例仍工作 |
| 订阅泄漏 | ctx/取消关闭 PubSub |
| 多实例重复事件 | 客户端幂等拉取完整状态 |
| Redis 连接数 | 每个 SSE 连接一个订阅；后续可共享订阅 |
