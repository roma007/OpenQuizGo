## 1. 目标

管理端提供「组卷预览」页面，直接调用已有 `POST /v1/admin/quiz/preview`，让教研在不发题、不建会话的情况下查看：

- 当前规则会抽到多少题、加权分与难度目标；
- 是否命中专题题包（`topic_id` / `topic_name`）；
- 具体题目、学段、难度、是否重复；
- 题池不足或专题回退等警告。

纯前端改动，不新增服务端接口。

## 2. 表单

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| 孩子 ID | 空 | 填写后服务端按孩子学段覆盖 `stage` |
| 学段 | low | preschool/low/mid/high |
| 年级标签 | g2 | 可选 |
| 解锁时长 | 20 | 1–240 |
| 加权门槛 | 3 | >0 |
| 学科权重 | 数学 2 / 语文 1 / 科学 1 / 趣味 0.5 | 至少一个非趣味学科 >0 |
| 趣味开关/上限 | 开 / 2 | 上限 0–10 |
| 每日上限 | 60 | 1–720 |
| 时区 | Asia/Shanghai | |
| 最大题数 | 0 | 0 表示按规则推导 |
| 随机种子 | 0 | 0 表示随机；相同种子结果可复现 |

## 3. 结果展示

- 概览：模式（专题/普通）、专题名、题数、最高加权分、难度目标、种子；
- 警告：`topic_mode`、`repeat_question`、`quota_redistributed`、`difficulty_fallback` 等；
- 题目表：序号、题目 ID、学科、学段、类型、难度、是否重复；
- 错误：显示 `code` / `message`，保留服务端警告。

## 4. 交互

- 页面加载不自动请求，避免空跑；
- 「开始预览」提交表单；「重置」恢复默认；
- 结果区域只在请求成功后替换，失败显示错误并保留上次结果。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 表单参数不合法 | 前端约束 + 服务端 422 提示 |
| 预览误以为已发题 | 页面文案注明「仅预览，不生成会话」 |
| 专题被其他专题抢占 | 预览显示实际命中的 topic_name；可下线其他专题后重试 |
