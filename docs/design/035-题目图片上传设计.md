## 1. 目标

管理端支持为题干上传图片并预览，保存到 `stem_media`：

- 支持 JPEG/PNG/WebP/GIF；
- 单文件 ≤5MB；
- 上传后返回相对 URL，题目表单保存 `{"url":"/v1/media/<name>"}`；
- 图片通过公开只读 URL 提供，TV/家长端后续可直接加载。

## 2. 存储

- 本地目录 `UPLOAD_DIR`（默认 `./data/uploads`）；
- 文件名随机 hex + 扩展名；
- 生产可替换为 S3/对象存储，接口不变。

## 3. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/v1/admin/media` | multipart `file`，管理员 `question.write` |
| GET | `/v1/media/{name}` | 公开只读图片 |

响应：`{"url":"/v1/media/<name>","bytes":123,"content_type":"image/png"}`。

## 4. 前端

- QuestionEdit 题干下方增加「上传图片」；
- 上传成功显示缩略图与移除按钮；
- 保存题目时写入 `stem_media`；
- 编辑已有题目时回显。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 恶意文件 | MIME 检测 + 扩展名白名单 + 大小限制 |
| 路径穿越 | 只允许 `filepath.Base` 且拒绝 `..` |
| 磁盘占满 | 限制大小；后续接对象存储 |
| 图片无法访问 | URL 相对路径，由服务端同源提供 |
