## 1. 目标

第 5 期「会员体系」第一步，建立可本地验收的会员与权益基础：

- 管理端维护会员套餐（月卡/年卡等）；
- 家长端查看会员状态、套餐与订单；
- 下单后使用**模拟支付**立即开通/续费；
- 会员到期时间可累计，权益字段先行存储，暂不控制具体功能。

不接入真实微信/支付宝支付；不引入退款、发票、订阅自动续费。

## 2. 概念

| 概念 | 说明 |
| --- | --- |
| 套餐 `membership_plan` | 名称、code、时长、价格、权益列表、上下线状态 |
| 订单 `membership_order` | 家长下单快照，含套餐名/金额/时长 |
| 会员 `account_membership` | 每个家长账号一条，记录当前套餐与到期时间 |

## 3. 数据模型

```sql
create table membership_plan (
  id uuid primary key default gen_random_uuid(),
  code text unique not null,
  name text not null,
  description text not null default '',
  duration_days int not null check (duration_days between 1 and 3650),
  price_cents int not null check (price_cents >= 0),
  features jsonb not null default '[]',
  status text not null default 'draft' check (status in ('draft','online','offline')),
  sort int not null default 0,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table membership_order (
  id uuid primary key default gen_random_uuid(),
  order_no text unique not null,
  account_id uuid not null references parent_account (id) on delete cascade,
  plan_id uuid not null references membership_plan (id),
  plan_name text not null,
  amount_cents int not null,
  duration_days int not null,
  status text not null default 'pending' check (status in ('pending','paid','cancelled')),
  channel text not null default 'mock',
  created_at timestamptz not null default now(),
  paid_at timestamptz
);

create table account_membership (
  account_id uuid primary key references parent_account (id) on delete cascade,
  plan_id uuid references membership_plan (id) on delete set null,
  plan_name text not null,
  status text not null default 'active' check (status in ('active','expired')),
  starts_at timestamptz not null default now(),
  expires_at timestamptz not null,
  updated_at timestamptz not null default now()
);
```

种子套餐：月度会员（30 天，¥19.9）、年度会员（365 天，¥169）。

## 4. 接口

### 家长端（家长令牌）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/family/membership` | 当前会员 + 在线套餐 |
| GET | `/v1/family/membership/orders` | 最近 20 条订单 |
| POST | `/v1/family/membership/orders` | `{plan_id}` 创建待支付订单 |
| POST | `/v1/family/membership/orders/{orderID}/pay` | 模拟支付并开通/续费 |

### 管理端（`membership.read` / `membership.write`）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/admin/membership/plans` | 套餐列表 |
| POST | `/v1/admin/membership/plans` | 新建套餐 |
| PUT | `/v1/admin/membership/plans/{id}` | 修改套餐 |
| DELETE | `/v1/admin/membership/plans/{id}` | 删除未被订单引用的套餐 |

## 5. 规则

- 只有 `online` 套餐可下单；
- 支付幂等：订单已支付时重复调用返回当前会员状态，不重复累加；
- 续费从 `max(now, 当前到期时间)` 起算，叠加套餐天数；
- 会员状态由 `expires_at` 计算：未到期 `active`，到期 `expired`；
- 金额使用分存储，前端按元展示；
- 管理端删除套餐时若已有订单引用返回 409，建议下线。

## 6. 前端

- 管理端新增「会员套餐」页面：列表、新建/编辑、上下线、删除；
- 家长端设置页新增「会员中心」：当前状态、套餐卡片、模拟支付确认、订单记录；
- 价格、时长、权益在套餐卡片展示。

## 7. 风险

| 风险 | 对策 |
| --- | --- |
| 模拟支付被误认为真实支付 | 页面与接口明确标注「模拟支付」 |
| 重复点击重复开通 | 订单状态 + 事务锁 + 幂等返回 |
| 删除套餐破坏历史订单 | 订单保存套餐快照；有引用时拒绝删除 |
| 权益未真正生效 | 本期只存储，后续接入具体功能开关 |
