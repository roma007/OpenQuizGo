## 1. 目标

家长可给家长端 App 增加本地 4 位儿童锁，避免孩子打开 App 修改规则或远程解锁：

- 启动/回到前台时要求输入儿童锁 PIN；
- 设置页开启、修改、关闭；
- 与服务端家长 PIN 独立，不上传。

## 2. 存储

SharedPreferences：

| 键 | 说明 |
| --- | --- |
| `app-lock:enabled` | 是否开启 |
| `app-lock:salt` | 随机盐（base64） |
| `app-lock:hash` | SHA-256(salt + PIN) |

- 不存明文 PIN；
- 关闭需验证当前儿童锁 PIN；
- 忘记 PIN 只能清除 App 数据（文档说明）。

## 3. 交互

- `AppLockGate` 包裹路由内容；
- 开启时启动即锁定；`AppLifecycleState.paused/inactive` 后回前台重新锁定；
- 解锁页数字键盘 + 错误提示；
- 设置页开关与修改 PIN。

## 4. 安全

| 风险 | 对策 |
| --- | --- |
| 明文 PIN | 盐 + SHA-256 |
| 暴力尝试 | 本地输入限速（每次错误延迟/提示），服务端 PIN 仍独立 |
| 忘记 PIN | 清除数据；文档说明 |
| 与服务端混淆 | 文案明确「儿童锁仅保护本机 App」 |

## 5. 范围

仅家长端本地锁，不改变服务端鉴权与家长 PIN。
