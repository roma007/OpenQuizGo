## 1. 目标

家长在弱网下发起电视临时解锁失败时，可暂存请求并在 10 分钟内补发，避免重复操作。

## 2. 数据

SharedPreferences 键 `pending-unlock:<bindId>`：

```json
{"minutes":15,"saved_at":1730000000000}
```

- 每台设备只保留最新一条；
- TTL 10 分钟，过期自动清除；
- 不保存 PIN。

## 3. 流程

1. 远程解锁遇网络错误（`ApiException.statusCode == null`）→ 暂存分钟数；
2. 设备卡片显示「待补发解锁 X 分钟」与补发按钮；
3. 点击补发 → 输入 PIN → 调用现有解锁接口；
4. 成功或过期清除；业务错误保留至过期。

## 4. 安全

| 风险 | 对策 |
| --- | --- |
| 延迟授权造成意外观看 | 10 分钟 TTL + 用户主动补发 |
| PIN 泄漏 | 不持久化 PIN |
| 重复补发 | 成功后立即清除 |

## 5. 范围

仅临时解锁补发；规则保存队列见 053。
