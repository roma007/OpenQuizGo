## 1. 背景与目标

第 5 期「亲子对战」第一步。当前只有一台家庭手机可稳定验收，TV 局域网仍不可达，因此 MVP 采用**同一设备轮流答题**：

1. 家长在家长端发起对战，服务端固定 5 道题；
2. 孩子先答，答完把手机交给家长；
3. 家长答同一组题；
4. 服务端判分并返回胜负与逐题解析。

不做实时双设备同步；后续再扩展「第二台设备输入房间码加入」。

## 2. 规则

- 每局固定 5 题（可扩展 3–10），从在线 `choice`/`image` 题中随机抽取，优先孩子学段；
- 孩子先答、家长后答，各自只能提交一次；
- 每题答对 +1 分，总分高者胜，相同为平局；
- 对战不发放每日积分，不影响连续天数；
- 对战记录保留在服务端，家长可重复发起新对局。

## 3. 数据模型

```sql
create table family_battle (
  id uuid primary key default gen_random_uuid(),
  family_id uuid not null references family(id) on delete cascade,
  child_id uuid not null references child_profile(id) on delete cascade,
  status text not null default 'child_turn'
    check (status in ('child_turn','parent_turn','finished')),
  question_ids jsonb not null,
  child_score int not null default 0,
  parent_score int not null default 0,
  created_by uuid,
  created_at timestamptz not null default now(),
  finished_at timestamptz
);

create table family_battle_answer (
  id bigserial primary key,
  battle_id uuid not null references family_battle(id) on delete cascade,
  side text not null check (side in ('child','parent')),
  question_id uuid not null references question(id),
  answer jsonb not null,
  correct boolean not null,
  position int not null,
  created_at timestamptz not null default now(),
  unique (battle_id, side, question_id)
);
```

## 4. 接口（家长令牌）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/v1/family/children/{childID}/battles` | 创建对局，body 可带 `question_count`（默认 5） |
| GET | `/v1/family/children/{childID}/battles/{battleID}` | 查询状态与题目 |
| POST | `/v1/family/children/{childID}/battles/{battleID}/answers` | 提交当前一方答案 |

提交体：

```json
{"side":"child","answers":[{"question_id":"...","answer":["a"]}]}
```

响应（进行中）：

```json
{"id":"...","status":"child_turn","question_count":5,
 "questions":[{"id":"...","stem":"...","type":"choice","options":[...]}],
 "child_score":0,"parent_score":0}
```

响应（结束）：

```json
{"...":"...","status":"finished",
 "result":{"winner":"child","child_score":3,"parent_score":2},
 "answers":[{"side":"child","question_id":"...","answer":["a"],"correct":true,
             "correct_answer":["a"],"explain":"..."}]}
```

## 5. 前端流程

```
孩子卡片 → 亲子对战
  → 开始对战（创建）
  → 孩子答题（逐题选择 → 提交）
  → 交接页「把手机交给家长」
  → 家长答题
  → 结果页（比分/胜负/逐题解析）
  → 再来一局
```

- 大字号题干与选项；
- 未提交前可修改选项；
- 提交失败显示服务端错误并保留答案；
- 结果页按题展示双方对错。

## 6. 校验与错误

| 场景 | 返回 |
| --- | --- |
| 题库不足 5 题 | 409 `QUESTION_POOL_EMPTY` |
| 重复提交同一方 | 409 `BATTLE_TURN_INVALID` |
| 答案缺题/多题 | 422 `VALIDATION_ERROR` |
| 非本家庭孩子 | 404 `CHILD_NOT_FOUND` |
| 对局不存在 | 404 `BATTLE_NOT_FOUND` |

## 7. 风险

| 风险 | 对策 |
| --- | --- |
| 孩子看到家长答案 | 未结束前不下发正确答案与解析 |
| 中途退出 | 对局保留，重新进入可继续当前一方 |
| 同设备轮流被误解为实时对战 | 页面明确「轮流答题」；双设备留后续 |
| 题库不足 | 创建前校验并提示 |
