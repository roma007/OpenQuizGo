## 1. 目标

在家长端主动提醒会员到期，降低权益中断：

- 会员剩余 ≤7 天：全局顶部横幅「会员将在 N 天后到期」；
- 会员已到期：横幅「会员已到期，会员权益已暂停」；
- 横幅可一键进入会员中心续费；
- 设置页会员入口实时显示当前状态；
- 会员中心即将到期时使用醒目样式。

不引入服务端推送/短信；提醒在 App 打开时基于会员接口实时计算。

## 2. 规则

| 状态 | 横幅 | 设置入口副标题 |
| --- | --- | --- |
| 无会员 | 不显示 | 查看会员状态、套餐与订单（模拟支付） |
| 有效且 >7 天 | 不显示 | 套餐名 · 有效期至 日期 |
| 有效且 ≤7 天 | 黄色「会员将在 N 天后到期」 | 套餐名 · 有效期至 日期 |
| 已到期 | 红色「会员已到期，会员权益已暂停」 | 会员已到期，点击续费 |

- `N = days_remaining`，最小显示 1 天；
- 横幅仅在拿到会员数据后展示，接口失败不打扰；
- 横幅位于所有 Tab 内容上方，切换 Tab 不重复叠加。

## 4. 测试

- Widget：≤7 天显示黄色提醒、到期显示红色提醒、>7 天不显示；
- Widget：点击横幅进入会员中心（可用 Navigator observer 或页面栈断言）；
- 模拟器：把到期时间改为 3 天后，重启 App 查看横幅与跳转。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 横幅打扰 | 仅在到期/7 天内显示，无会员不显示 |
| 接口失败导致空白 | 失败时隐藏，不阻塞主界面 |
| 多 Tab 重复 | 横幅只放在 Shell 内容区外层 |
| 时区差异 | 使用服务端返回的 days_remaining |
