## 1. 背景与目标

- 题库难度目前由人工设定，缺少数据反馈；
- `answer_log` 已记录每题作答与对错；
- 目标：统计每题正确率，给出难度调整建议，管理员确认后批量应用并审计。

## 2. 规则

| 条件（样本 ≥ min_answers） | 建议 |
| --- | --- |
| accuracy ≥ 0.85 | 难度 +1（最高 5） |
| accuracy ≤ 0.40 | 难度 -1（最低 1） |
| 其他 | 保持不变 |

- 默认 `min_answers=20`，可在预览时调整（5–1000）；
- 仅统计 `status='online'` 的题；
- 应用时仅修改 `difficulty`，`version+1`，写审计 `question.calibrate`。

## 3. 接口

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/v1/admin/calibration/preview?min_answers=20&limit=100` | question.read | 返回建议列表 |
| POST | `/v1/admin/calibration/apply` | question.write | `{items:[{question_id,difficulty}]}` |

预览响应：
```json
{"items":[{"question_id":"...","stem":"...","subject":"math","stage":"low",
"difficulty":2,"answered":30,"correct":27,"accuracy":0.9,
"suggested_difficulty":3,"reason":"正确率 90%，建议提高难度"}],
"thresholds":{"min_answers":20,"up":0.85,"down":0.4}}
```

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 样本少导致误判 | min_answers 门槛 + 仅给建议，人工确认 |
| 批量误操作 | 前端勾选 + 二次确认；服务端审计 |
| 难度频繁变动 | 同一题可重复校准，记录版本与审计 |
