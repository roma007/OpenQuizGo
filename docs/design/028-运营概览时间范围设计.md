## 1. 目标

运营概览趋势支持 **7 / 30 / 90 天** 切换，缓存按范围隔离，避免不同范围互相覆盖。

## 2. 接口

`GET /v1/admin/dashboard?days=7|30|90`

- 默认 7；
- 非法值返回 422；
- `trend` 长度等于所选天数；
- 其他指标口径不变。

## 3. 缓存

- 每种天数独立缓存 30 秒；
- 相同范围 30 秒内 `generated_at` 不变；
- 范围切换不会清空其他范围缓存。

## 4. 前端

- 趋势卡右上角 Segmented：7 天 / 30 天 / 90 天；
- 切换后重新请求并更新标题；
- 进度条按当前范围最大金额归一化；
- 其他指标不随范围变化（仍为当前全局值）。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 90 天数据量大 | 单次聚合 + created_at 索引；后续可预聚合 |
| 缓存 key 混乱 | map[int]cacheEntry |
| 非法参数 | 服务端白名单 |
