## 1. 目标

在排行榜中按战绩自动展示勋章，增强家庭对战激励：

| 勋章 | 条件 |
| --- | --- |
| 首胜 `first_win` | 至少 1 胜 |
| 三连胜 `streak_3` | 最佳连胜 ≥3 |
| 十战 `veteran` | 完成 ≥10 场 |
| 全胜 `all_win` | ≥3 场且全胜 |
| 榜首 `champion` | 当前榜单第 1 名且有对局 |

勋章由服务端按所选周期计算，不新增数据表。

## 2. 接口

`RankingEntry` 增加 `medals: string[]`。

排序与统计不变；`champion` 在排序后按名次生成。

## 3. 前端

- 排行榜卡片在战绩下方显示勋章 Chip；
- 文案映射：首胜/三连胜/十战/全胜/榜首；
- 无勋章不展示。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 周期切换勋章变化 | 符合预期，按当前周期计算 |
| 并列第一 | 当前实现按排序后第一名给 champion |
