## 1. 目标

家长在弱网/离线时修改观看规则，不再直接失败：

- 规则暂存到本地；
- 联网后在规则页提示并输入 PIN 同步；
- 只保留每个孩子最新一条待同步规则；
- 不在本地保存 PIN。

## 2. 数据

SharedPreferences 键 `pending-rule:<childId>`：

```json
{"saved_at":1730000000000,"rule":{...Rule JSON...}}
```

- 每次保存覆盖旧记录；
- 同步成功或用户主动放弃时清除；
- 不存 PIN、不存令牌。

## 3. 流程

1. 保存规则时先请求服务端；
2. 网络错误（`ApiException.statusCode == null`）→ 写入待同步队列并提示；
3. 规则页加载时读取待同步记录，回填表单并展示提示条；
4. 点击「同步」→ 输入 PIN → 调用现有更新接口；
5. 成功清除本地记录并刷新规则；业务错误（4xx/5xx）保留记录并提示。

## 4. 安全

| 风险 | 对策 |
| --- | --- |
| PIN 泄漏 | 不持久化 PIN，仅同步时临时输入 |
| 旧规则覆盖新规则 | 每孩子只保留最新一条，保存时间可见 |
| 离线修改冲突 | 同步走服务端版本校验；失败保留待同步 |

## 5. 范围

本期只做规则保存队列；设备临时解锁补发另行设计（涉及授权时效与安全）。
