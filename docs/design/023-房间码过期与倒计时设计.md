## 1. 目标

房间码默认 10 分钟有效，避免长期可加入；家长端显示有效期与倒计时，过期后提示重新创建。

## 2. 规则

- 创建房间时写入 `join_code_expires_at = now() + 10 分钟`；
- 加入时校验房间未过期，过期返回 409 `ROOM_EXPIRED`；
- 状态接口返回 `join_code_expires_at`，结束时不再返回；
- 家长端等待页显示「剩余 mm:ss」；
- 同设备模式不写过期时间。

## 3. 数据模型

```sql
alter table family_battle add column join_code_expires_at timestamptz;
create index ... on family_battle (join_code_expires_at) where join_code is not null;
```

## 4. 接口变化

- `State` 增加 `join_code_expires_at`（仅 room 且未结束）；
- `POST /battles/join` 过期返回 409。

## 5. 前端

- 等待页显示剩余时间，每分钟/秒刷新；
- 剩余 0 时显示「房间码已过期，请重新创建」并停止轮询；
- 其他流程不变。

## 6. 风险

| 风险 | 对策 |
| --- | --- |
| 客户端时钟不准 | 以服务端过期时间为准，倒计时仅展示 |
| 过期房间占用码 | 6 位随机空间足够；后续可清理 |
| 轮询继续请求 | 过期后停止轮询 |
