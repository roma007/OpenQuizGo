## 1. 目标

在已有单题校准历史之外，提供：

- 近 N 天校准活动趋势（按天、升降分布）；
- 批量撤销多道题最近一次校准，避免误操作后逐题处理。

## 2. 趋势接口

`GET /v1/admin/calibration/trend?days=30`

```json
[{"date":"2026-11-05","changes":2,"up":1,"down":1}]
```

- 权限 `question.read`；
- `days` 默认 30，最大 365；
- 数据来自 `audit_log(action='question.calibrate')`，按数据库日期聚合；
- 仅返回有记录的日期。

## 3. 批量撤销

`POST /v1/admin/calibration/rollback`

```json
{"question_ids":["..."]}
```

- 权限 `question.write`，1–200 题；
- 每题取最近一条 `rollback=false` 的校准记录；
- 仅当题目在线且当前难度等于该记录 `to` 时，回退到 `from`；
- 写新审计 `{"from":current,"to":from,"rollback":true}`；
- 返回 `{applied, skipped}`；
- 重复撤销时，最近非回滚记录仍指向旧目标难度，因当前难度不匹配而跳过，避免来回切换。

## 4. 管理端

- 校准页展示近 30 天横向条形趋势；
- 复用行选择，「撤销最近校准」批量操作；
- 历史弹窗显示「回滚」标签。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 误撤销已被再次修改的题 | 当前难度必须等于最近 to |
| 重复撤销来回切换 | 回滚审计标记 rollback=true，不作为最近记录 |
| 时区偏差 | 按数据库会话时区聚合，文档说明 |
