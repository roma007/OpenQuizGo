## 1. 目标

在现有学科/学段/题型覆盖率之外，增加按专题题包聚合与 CSV 导出，便于运营发现专题题量不足。

## 2. 接口

`GET /v1/admin/coverage/topics?threshold=50`

```json
{"cells":[{"topic_id":"...","topic_name":"寒假数学","status":"online","count":12}],"total":120,"warnings":["专题「寒假数学」上线题量 12，低于阈值 50"]}
```

`GET /v1/admin/coverage/export?threshold=50&dimension=topic`

- `dimension` 默认 `matrix`（保持现有 CSV）；
- `dimension=topic` 输出 `topic_id,topic_name,status,count`；
- 权限 `question.read`。

专题归属以 `question_topic` 多对多关系为准；同一题属于多个专题时分别计数；未加入专题的题目单独汇总为 `unassigned`。

## 3. 管理端

- 覆盖率页增加「专题覆盖」卡片/表格；
- 增加「导出专题 CSV」按钮；

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 多专题重复计数 | 明确按关系计数，total 用去重题量 |
| 未分专题漏统计 | `unassigned` 兜底行 |
| 大表查询慢 | 现有索引 + 聚合查询 |
