## 1. 目标

家长可为已支付订单提交发票申请，管理端查看/标记开具或驳回；本期不接税务/开票服务。

## 2. 数据

`membership_invoice`：

| 字段 | 说明 |
| --- | --- |
| `order_id` | 唯一，关联订单 |
| `account_id` | 申请人 |
| `title_type` | personal/company |
| `title` | 抬头 |
| `tax_no` | 税号（企业必填） |
| `email` | 接收邮箱 |
| `amount_cents` | 订单实付金额 |
| `status` | requested/issued/rejected |
| `remark` | 管理端备注 |
| `created_at/issued_at/updated_at` | 时间 |

## 3. 接口

- 家长：`POST /family/membership/orders/{orderID}/invoice`、`GET /family/membership/invoices`；
- 管理：`GET /admin/membership/invoices?status=&limit=`、`PUT /admin/membership/invoices/{id}`；
- 仅已支付且属于本人的订单可申请；每单一次；
- 企业抬头必须有税号。

## 4. UI

- 家长端订单卡片：已支付订单显示「申请发票」，弹窗填写抬头/税号/邮箱；
- 管理端新增「发票申请」页面：列表、标记已开具/驳回并填写备注。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 重复申请 | order_id 唯一 |
| 未支付申请 | 服务端校验 paid |
| 税号缺失 | 企业必填校验 |
| 隐私 | 仅本人与管理员可读 |

## 6. 后续
