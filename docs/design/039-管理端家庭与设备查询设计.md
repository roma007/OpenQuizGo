## 1. 目标

为运营/客服提供家庭与设备查询：

- 家庭列表：孩子数、活跃设备数、会员状态/到期；
- 按家庭 ID、孩子昵称、设备 ID 搜索；
- 家庭详情：成员、孩子、设备绑定（平台/状态/绑定时间）；
- 不返回手机号等敏感信息。

## 2. 权限

新增 `family.read`，授予超级管理员与运营。

## 3. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/admin/families?query=&limit=&offset=` | 家庭列表 + 总数 |
| GET | `/v1/admin/families/{id}` | 家庭详情 |

列表项：

```json
{"family_id":"...","owner_id":"...","member_status":"free",
 "members":1,"children":1,"devices":1,
 "membership_status":"active","plan_name":"月度会员","expires_at":"...",
 "created_at":"..."}
```

详情增加 `members[]`、`children[]`、`devices[]`。

## 4. 前端

- 菜单「家庭设备」；
- 搜索框（家庭 ID/孩子昵称/设备 ID）+ 表格；
- 详情弹窗展示成员、孩子、设备；
- 空态/加载失败提示。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 敏感信息 | 不返回手机号/令牌 |
| 大表查询 | 分页 + 条件搜索；后续加索引 |
| 权限越界 | `family.read` 控制 |
