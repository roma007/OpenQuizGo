## 1. 目标

允许家庭 owner 开关会员共享：

- 开启：家庭成员共享 owner 的会员权益（付费专题等）；
- 关闭：仅 owner 的会员权益生效，其他成员自己的会员仍可用于自己。

## 2. 数据

`family.membership_shared boolean not null default true`。

## 3. 接口

- `GET /v1/family/membership/sharing` → `{shared, can_edit}`；
- `PUT /v1/family/membership/sharing` body `{shared}`，仅 owner；
- 会员中心返回 `sharing` 与 `membership.shared`。

## 4. 权益计算

- 会员中心：先看自身有效会员；无则若共享开启且 owner 会员有效，返回 owner 会员并标记 `shared=true`；
- 付费专题：家庭成员会员有效且（共享开启或该成员是 owner）时可用。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 非 owner 修改 | 服务端 403 |
| 关闭后缓存 | 会员中心实时查询 |
| 语义混淆 | UI 明确“家庭会员共享” |
