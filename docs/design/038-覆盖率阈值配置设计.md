## 1. 目标

覆盖率告警阈值从固定 50 改为可配置（1–10000），管理端可即时调整并刷新告警。

## 2. 接口

`GET /v1/admin/coverage?threshold=50`

- 默认 50；
- 非法值返回 422；
- 仅影响 warnings，不改变聚合 cells。

## 3. 前端

- 覆盖率页增加阈值 InputNumber + 刷新；
- 告警文案显示当前阈值；
- 导出 CSV 不包含阈值（仅 cells）。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 阈值过大导致大量告警 | 输入范围限制 + 用户确认 |
| 口径不一致 | 默认 50 保持兼容 |

## 5. 后续
