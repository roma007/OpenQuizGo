## 1. 目标

管理端首页提供运营概览，集中查看题库、专题、会员、对战与家庭数据：

- 关键指标卡片：题目总量/在线、专题在线、活跃会员、净收入、近 30 天订单、近 7 天对战；
- 最近订单列表；
- 7 天内到期会员列表；
- 题目状态分布。

纯读接口，不改变业务数据。

## 2. 指标定义

| 指标 | 定义 |
| --- | --- |
| 题目总量 | `question` 全部 |
| 在线题目 | `status='online'` |
| 专题在线 | `topic_pack.status='online'` |
| 专题生效中 | 在线且当前时间在 `start_at/end_at` 内 |
| 活跃会员 | `account_membership.status='active' and expires_at > now()` |
| 净收入 | `paid` 订单金额 − `refunded` 订单金额 |
| 近 30 天订单 | `membership_order.created_at > now()-30d` |
| 近 7 天对战 | `family_battle.status='finished' and finished_at > now()-7d` |
| 家庭/孩子 | `family` / `child_profile` 总数 |

## 3. 接口

`GET /v1/admin/dashboard`（权限 `dashboard.read`）

```json
{
  "questions": {"total": 2000, "online": 1800, "draft": 150, "review": 50},
  "topics": {"total": 5, "online": 3, "active": 2},
  "membership": {"active_members": 12, "revenue_cents": 39800, "orders_30d": 20, "paid_30d": 18},
  "families": 10,
  "children": 14,
  "battles_7d": 6,
  "recent_orders": [
    {"order_no": "M...", "plan_name": "月度会员", "amount_cents": 1990, "status": "paid", "created_at": "..."}
  ],
  "expiring_memberships": [
    {"account_id": "...", "plan_name": "月度会员", "expires_at": "...", "days_remaining": 3}
  ]
}
```

## 4. 权限

新增 `dashboard.read`：

- 超级管理员、运营可读；
- 教研/审核不可见。

## 5. 前端

- 菜单新增「运营概览」（Dashboard 图标），放在「题目管理」之前；
- 指标卡片 2×3 布局，移动端单列；
- 最近订单、即将到期会员两个表格；
- 手动刷新按钮，显示最近更新时间。

## 6. 风险

| 风险 | 对策 |
| --- | --- |
| 聚合查询慢 | 单次多查询、限制列表 5 条；后续可加缓存 |
| 指标口径不一致 | 文档固定定义，页面标注 |
| 数据权限 | 仅 dashboard.read；不返回家长手机号 |
