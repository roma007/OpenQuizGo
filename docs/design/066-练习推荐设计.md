## 1. 目标

基于孩子最近答题表现，推荐薄弱学科与可练习专题，帮助家长决定练习方向。

## 2. 规则（v1）

- 取最近 30 天答题记录，按学科统计正确率；样本 ≥5 才进入薄弱学科，取最低 3 个；
- 建议难度：整体正确率 <40% 降 1 级，>85% 升 1 级，否则保持；限制 1–5；
- 专题推荐：在线专题、匹配孩子学段，优先匹配薄弱学科，按题量排序取 3 个；
- 无足够答题数据时返回空薄弱学科与热门专题。

## 3. 接口

`GET /v1/family/children/{childID}/recommendations`

```json
{
  "child_id":"...",
  "weak_subjects":[{"subject":"math","answered":12,"correct":4,"accuracy":0.33}],
  "suggested_difficulty":2,
  "topics":[{"topic_id":"...","name":"寒假数学","reason":"匹配薄弱学科数学"}],
  "generated_at":"..."
}
```

- 家长鉴权 + 孩子归属校验。

## 4. 家长端

孩子卡片增加「推荐」入口，页面展示薄弱学科、建议难度与专题列表。

## 5. 风险

| 风险 | 对策 |
| --- | --- |
| 样本少误判 | 学科样本 ≥5 |
| 无数据 | 返回热门专题与提示 |
| 跨家庭访问 | 归属校验 |
