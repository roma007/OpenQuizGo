## 1. 目标

按天汇总会员订单支付、退款与优惠金额，供运营/财务核对内部账单；不接外部支付渠道对账。

## 2. 接口

`GET /v1/admin/membership/reconciliation?from=YYYY-MM-DD&to=YYYY-MM-DD`

```json
{
  "from":"2026-11-01","to":"2026-11-05",
  "days":[{"date":"2026-11-05","paid_count":2,"paid_cents":3000,
           "refunded_count":1,"refunded_cents":1000,
           "discount_cents":100,"net_cents":2000}],
  "totals":{"paid_count":2,"paid_cents":3000,"refunded_count":1,
            "refunded_cents":1000,"discount_cents":100,"net_cents":2000}
}
```

- 默认最近 30 天，最大 366 天；
- 支付按 `paid_at` 日期、退款按 `refunded_at` 日期归集；
- `net_cents = paid_cents - refunded_cents`。

`GET /v1/admin/membership/reconciliation/export?...` 返回 CSV。

## 3. 管理端

- 会员菜单新增「会员对账」；
- 日期范围选择、支付/退款/净额/优惠汇总卡片、按日表格、导出 CSV。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 日期参数非法 | 422 |
| 区间过大 | 最大 366 天 |
| 时区 | 按数据库日期聚合 |
