## 1. 目标

家长可开启自动续费预约：会员到期前 3 天，worker 自动创建一笔待支付续费订单，家长确认支付即可；本期不做免密自动扣款（需支付渠道代扣协议）。

## 2. 数据

`membership_auto_renew(account_id pk, plan_id, enabled, last_order_at, updated_at)`。

## 3. 接口

- `GET /v1/family/membership/auto-renew` → `{enabled, plan_id, plan_name, can_edit}`；
- `PUT /v1/family/membership/auto-renew` body `{enabled, plan_id}`；
- 会员中心返回 `auto_renew`。

## 4. worker

每次报告周期：

- 找出 `enabled=true` 且会员在 3 天内到期（或已过期 3 天内）的账号；
- 套餐在线；
- 若 `last_order_at` 在 24 小时内则跳过；
- 创建待支付订单并更新 `last_order_at`；
- 失败记录日志，不影响其他账号。

## 5. 家长端

会员中心新增「自动续费预约」开关与套餐选择；说明「到期前生成待支付订单，不会自动扣款」。

## 6. 风险

| 风险 | 对策 |
| --- | --- |
| 重复订单 | 24 小时节流 + last_order_at |
| 套餐下线 | 跳过并记录 |
| 免密扣款合规 | 本期不做扣款 |
| 过期用户 | 仅 3 天宽限期 |
