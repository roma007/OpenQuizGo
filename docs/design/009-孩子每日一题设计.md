## 1. 目标

第 4 期「孩子端互动」第一步：家长把手机递给孩子，在家长端进入「孩子模式」完成每日一题，累计积分与连续天数。

- 不新增独立 App/小程序；
- 使用家长令牌访问，家长可随时退出；
- 数据服务端持久化，跨设备一致。

## 2. 规则

- 每天 1 题，按 `child_id + 日期` 唯一；
- 题目从 `status=online` 的 choice/image 中按 `md5(question_id || date)` 确定性选择；
- 答对 +10 分；同一天不能重复作答；
- 连续天数 = 从今天（或昨天）向前连续有作答记录的天数；
- 积分 = 每日得分累计。

## 3. 接口（家长令牌）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/family/children/{childID}/daily` | 今日题目 + 是否已答 + 结果 + 连续天数/总分 |
| POST | `/v1/family/children/{childID}/daily/answers` | `{answer:["a"]}`，判分并落库 |

响应：
```json
{"date":"2026-11-04","question":{"id":"...","stem":"...","type":"choice","options":[{"id":"a","text":"..."}]},
 "answered":false,"streak":3,"total_points":40}
```

## 4. 数据模型

```sql
create table child_daily_answer (
  id bigserial primary key,
  child_id uuid not null references child_profile(id) on delete cascade,
  answer_date date not null,
  question_id uuid not null references question(id),
  correct boolean not null,
  points int not null default 0,
  answered_at timestamptz not null default now(),
  unique (child_id, answer_date)
);
```

## 5. 前端

- 「孩子」卡片增加「每日一题」入口；
- 大字号题干/选项，提交后显示对错、积分、连续天数；
- 已答状态展示结果与「明天再来」。

## 6. 风险

| 风险 | 对策 |
| --- | --- |
| 孩子退出到家长界面 | 家长自行保管手机；后续可加儿童锁 |
| 题目不足 | 无在线题时返回 409 提示 |
| 时区 | 使用孩子规则时区（默认 Asia/Shanghai） |
