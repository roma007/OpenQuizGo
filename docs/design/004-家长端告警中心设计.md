## 1. 背景与目标

- TV 端 T9 已把无障碍/使用情况/通知被关闭上报为 `tamper_event(permission_revoked)`；
- 家长端目前无法看到这些异常，也没有消息入口；
- 本次目标：家长端内置**告警中心**，展示设备权限异常等事件并标记已读；
- 非目标：FCM/APNs 系统推送（需要外部凭据，后续接入；本期预留事件模型）。

## 2. 需求与验收

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| R1 | 告警列表 | 按时间倒序显示事件类型、孩子、设备、时间 |
| R2 | 未读标记 | AppBar 铃铛显示未读数；进入列表后标记全部已读 |
| R3 | 空态/错误 | 无告警与网络失败均有明确提示 |
| R4 | 服务端持久化 | `tamper_event.read_at` 记录已读；重复读取不再计未读 |
| R5 | 兼容现有上报 | T9 上报的 `permission_revoked` 自动出现在列表 |

## 3. 方案

- 服务端新增 `GET /v1/family/alerts` 与 `POST /v1/family/alerts/read`，直接基于 `tamper_event`；
- 迁移 00008 增加 `read_at` 与 `(child_id, reported_at desc)` 索引；
- 客户端新增 `AlertsRepository`、`alertsProvider`、`AlertsPage`；HomeShell AppBar 增加铃铛 + 未读徽标；
- 本期不做系统推送；后续 FCM/APNs 复用同一事件模型。

## 4. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/family/alerts?limit=50` | 返回 `{items, unread}`；item 含 id/type/detail/reported_at/child_name/device_id/read |
| POST | `/v1/family/alerts/read` | 标记家庭全部告警为已读 |

错误：401/403 沿用身份中间件；limit 默认 50，最大 200。

## 5. 数据模型

```sql
alter table tamper_event add column read_at timestamptz;
create index tamper_event_child_reported_idx on tamper_event(child_id, reported_at desc);
```
