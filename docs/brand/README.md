# OpenQuizGo 品牌标识（Logo）

本目录存放 OpenQuizGo 的官方标识与导出资源。标识沿用 OpenReel 的「外环 + 中心图形」结构，中心图形由播放三角替换为本项目特征——**亲子（大人与身前的孩子）**。

## 一、构成

| 部件 | 说明 |
| --- | --- |
| 底板 | 深色满版方形（直角，铺满 1024×1024，无圆角、无透明区域） |
| 外环 | 环宽 116、外径 642（外半径 321、内半径 205），缺口开在 **3 点钟方向**，两端圆头，缺口半角 33° |
| 中心图形 | 一大一小两个人形：大人居后（头半径 46、肩宽 126），小孩居前（头半径 29、肩宽 84），两人体重叠约 26px，中间以 18px 底板色间隙区分前后层次；整体高约 354，居中于 (512, 512) |

中心图形全部为几何路径（圆 + 平肩身体），不依赖任何字体或图标库。

## 二、色板

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 底板渐变（上） | `#1C2732` | 深蓝灰 |
| 底板渐变（下） | `#0E161D` | 近黑 |
| 外环渐变（起） | `#7CC4FF` | 天蓝，位于左上 |
| 外环渐变（止） | `#2F6BFF` | 宝蓝，位于右下 |
| 中心图形渐变（上） | `#5FE3A0` | 薄荷绿 |
| 中心图形渐变（下） | `#2BB673` | 深绿 |

语义：蓝色 = 家长端的守护与管控，绿色 = 孩子与成长；两者叠在一起即「家长护着孩子」。

## 三、文件清单

| 文件 | 用途 |
| --- | --- |
| `logo.svg` | 主标识（直角满版，1024 母版，可任意缩放） |
| `logo-1024.png` / `logo-512.png` / `logo-192.png` / `logo-48.png` | 常用尺寸导出 |

## 四、使用规范

- 最小使用尺寸：**48px**（再小两个人形会糊成一个色块，此时改用「并排」简化版或直接使用纯色外环版）。
- 安全留白：四周至少保留图形外径的 1/8（1024 网格下约 80px）。
- 禁止：改变外环缺口角度、旋转外环、替换渐变方向、把两个人物合并成单色实心块、在标识上叠加文字。
- 浅色背景下请先使用深色底板版本，不要把外环直接放到白色背景上（浅蓝会失去对比）。

## 五、再生成

图形全部由参数决定，关键参数：`R_OUT` / `R_IN`（环内外半径）、`GAP`（缺口半角）、`figure()` 的头半径 / 肩宽 / 底部基线、`HALO`（人物之间的间隙宽度）。修改参数后重新导出 SVG，再用任意 SVG 渲染器输出 PNG 即可（本仓库资源由 `qlmanage` 渲染）。

> 备选方向（未采用，可留档参考）：中央问号、对勾、沙漏、锁、钥匙、播放三角挖锁孔、亲子并排 / 手拉手。
