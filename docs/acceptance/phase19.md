## 1. 结论

**通过。** 会员剩余 ≤7 天时，家长端所有 Tab 顶部显示黄色提醒；到期后显示红色提醒；点击横幅进入会员中心；设置入口与会员中心状态同步。

## 2. 交付

- 新增全局 `MembershipBanner`：7 天内 / 已到期两种状态，点击进入会员中心并刷新；
- Shell 内容区顶部接入横幅，切换 Tab 不重复；
- 设置页会员入口副标题动态显示有效期或到期提示；
- 会员中心即将到期使用黄色状态卡与「仅剩 N 天」文案；
- 无服务端改动，基于 `days_remaining` 实时计算。

## 3. 验证

```text
flutter test    34 passed（含 4 个横幅用例）
```

模拟器实测（把到期时间改为 3 天后）：

| 步骤 | 结果 |
| --- | --- |
| 重启 App | 孩子页顶部显示黄色横幅「会员将在 3 天后到期」+「去续费」 |
| 点击横幅 | 进入会员中心 |
| 会员中心 | 黄色「会员即将到期」，有效期至 2026-11-08（仅剩 3 天），权益标签正常 |
| 恢复 30 天 | 横幅消失，状态卡恢复绿色「会员有效」 |

截图：`docs/acceptance/phase19/01-expiring-banner.png`、`02-expiring-membership.png`。

## 4. 限制

- 仅在 App 打开/刷新时计算，无服务端推送或短信；
- 接口失败时隐藏横幅，不提示错误；
- 无分级提醒（30/7/1 天）与免打扰设置。

## 5. 后续

- 服务端定时任务 + 推送/短信；
- 到期前 30/7/1 天分级提醒；
- 自动续费与优惠券引导。
