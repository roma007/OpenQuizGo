## 1. 结论

**通过。** 管理端可创建/编辑优惠券；家长下单可使用优惠码，订单记录原价、优惠、实付；退款归还使用次数。管理端构建、E2E、Go/Flutter 测试通过。

## 2. 交付

- 迁移 `00026_membership_coupon.sql`（已应用到开发库，版本 26）；
- 管理端 `GET/POST /admin/membership/coupons`、`PUT /{id}`；
- 家长端 `POST /family/membership/coupons/validate`；
- 创建订单支持 `coupon_code`，事务内校验/锁定/次数 +1；
- 订单新增原价/优惠/优惠码，退款归还次数；
- 管理端「优惠券」页面；
- 家长端支付对话框支持优惠码。

## 4. 限制

- 仅固定金额券，未支持百分比/定向/叠加；
- 优惠券创建后未做删除，仅支持停用；
- 家长端未在下单前展示试算金额，仅成功提示优惠金额；
- 未实现优惠券使用明细审计。
