## 1. 结论

**通过（服务端测试）。** `device_bind` 增加 `last_seen_at`，设备鉴权成功时节流刷新；worker 按 `DEVICE_STALE_DAYS`（默认 30，0 关闭）自动解绑长期无活动设备，清理恢复出厂/卸载后的残留绑定。

## 2. 交付

- 迁移 `00025_device_last_seen.sql`（已应用到开发库，版本 25）；
- DeviceAuth 成功后刷新 `last_seen_at`（5 分钟节流）；
- `identity.UnbindStaleDevices`：解绑超过阈值的 active 设备并清空 token；
- 配置 `DEVICE_STALE_DAYS`，默认 30，0 关闭；
- worker 每个报告周期执行一次并记录数量。

## 3. 验证

```text
go test -p 1 ./...（测试库/Redis）      全部通过
go run ./cmd/migrate up                 OK 00025
go build ./...                          通过
```

identity 集成测试覆盖：40 天无活动设备被解绑、原令牌立即失效（403）、近期设备保持 active。

## 4. 限制

- 不是恢复出厂即时感知，最长 30 天后清理；
- 不做设备指纹；
- 解绑不撤销已签发授权；
- 未提供管理端手动清理预览。

## 5. 后续
