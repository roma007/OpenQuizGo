## 5. 验证证据

### 5.1 自动化测试

```text
go vet ./...                      通过
go test -p 1 ./...                通过
  internal/identity               TestIdentityFlow
  internal/question               TestQuestionWorkflow
  internal/quiz                   TestSelectWithRealPool / TestSessionFlow / TestSessionIssuesGrant
  internal/rule                   TestRuleService + 规则单元测试
  internal/watch                  TestGrantAndHeartbeat / TestConcurrentIssueRespectsDailyLimit / TestOfflineLease
  internal/report                 TestGenerateWeeklyReport / TestPeriodStart
```

关键断言：

- 设备解绑后令牌立即 403。
- 非法题目状态流转 409；editor 无发布权限 403。
- 同一 seed 组卷结果一致；下线题/近 30 天已答题不入选。
- 题目令牌重放 409；会话过期 410；快速作答标记 suspicious。
- 时段外创建会话 403；每日额度用尽 403。
- 100 并发签发、日额度 3 分钟 → 仅 3 成功，总额 3 分钟。
- 答题期间心跳不扣减；时段外心跳吊销授权。
- 离线租约 EdDSA 验签通过；重复对账 409；超额截断。
- 周报趣味题不进入学科统计；重复生成不新增行。

- 登录 → 建孩子 → 设备激活 → 答题 7.5 分 → 授权 20 分钟。
