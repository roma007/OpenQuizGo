## 1. 结论

**通过。** 家长可开启自动续费预约；worker 在会员到期前 3 天自动创建待支付续费订单，24 小时内不重复；本期不做免密自动扣款。

## 2. 交付

- 迁移 `00030_membership_auto_renew.sql`（已应用到开发库，版本 30）；
- `GET/PUT /family/membership/auto-renew`；
- 会员中心返回 `auto_renew`；
- worker 每个周期扫描到期窗口并创建待支付订单；
- 家长端会员中心「自动续费预约」开关与套餐选择。

## 4. 限制

- 不免密扣款，需家长确认支付；
- 仅到期前/过期 3 天窗口；
- 未做续费失败通知与重试；
- 未做真机 UI 走查。
