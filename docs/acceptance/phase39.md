## 1. 结论

**通过。** 运营可按家庭 ID、孩子昵称、设备 ID 搜索家庭，查看成员、孩子、设备与会员状态；不返回手机号/令牌。

## 2. 交付

- 新权限 `family.read`（超级管理员/运营）；
- `GET /v1/admin/families?query=&limit=&offset=`；
- `GET /v1/admin/families/{id}` 详情；
- 管理端「家庭设备」页面：搜索、列表、详情弹窗；
- 详情含成员/孩子/设备（平台、状态、绑定时间）。

## 4. 限制

- 列表按家庭，无单独设备全局列表；
- 不展示手机号（加密字段）与设备令牌；
- 无解绑/客服工单操作。
