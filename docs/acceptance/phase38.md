## 1. 结论

**通过。** 覆盖率接口支持 `threshold`（1–10000），默认 50；管理端可输入阈值并刷新，告警文案显示当前阈值。

## 2. 交付

- `GET /v1/admin/coverage?threshold=` 与导出接口支持阈值；
- 非法/越界返回 422；
- 默认 50 保持原行为；
- 管理端覆盖率页增加阈值 InputNumber + 刷新；
- 告警标题显示当前阈值。

## 3. 验证

```text
go test ./...                                      passed
TEST_DATABASE_URL go test ./internal/question      passed（阈值/422）
npm run build（管理端）                             passed
```

接口实测：

```text
threshold=50   → 200，1 条告警
threshold=10000→ 200，2 条告警
threshold=0    → 422
threshold=abc  → 422
```

## 4. 限制

- 阈值全局，不支持按学科/学段分别设置；
- 未持久化配置，刷新后回到默认 50；
- 导出 CSV 仅包含 cells，不包含阈值。
