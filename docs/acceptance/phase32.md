## 1. 结论

**通过。** 订单列表可打开详情弹窗，展示订单基本信息、渠道、外部交易号、退款原因/操作人及退款前后会员快照。

## 2. 交付

- 订单表操作列新增「详情」；
- 详情弹窗：订单号、状态、套餐、金额、时长、渠道、外部交易号、账号、创建/支付/退款时间；
- 退款原因与操作人；
- 退款前后会员快照（状态/套餐/到期时间），缺失显示「—」；
- 退款流程保持不变。

## 3. 验证


## 4. 限制

- 只读弹窗，无导出/打印；
- 操作人显示 UUID，未反查管理员用户名；
- 快照未做字段差异高亮。

## 5. 后续

- 操作人姓名反查；
- 快照差异高亮；
- 订单对账/发票入口。
