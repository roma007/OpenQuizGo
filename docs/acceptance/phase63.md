## 1. 结论

**通过。** 新增按日对账聚合与 CSV 导出；管理端「会员对账」页面展示日期范围、支付/退款/优惠/净额汇总与明细。内部对账可用，不含外部渠道流水。

## 2. 交付

- `GET /v1/admin/membership/reconciliation?from=&to=`；
- `GET /v1/admin/membership/reconciliation/export` CSV；
- 默认最近 30 天，最大 366 天，非法日期 422；
- 支付按 `paid_at`、退款按 `refunded_at` 归日；
- 管理端对账页面（日期范围、汇总卡片、按日表格、导出）。

## 3. 验证

```text
go test -p 1 ./...（测试库/Redis）      全部通过
管理端 npm run build                    通过
管理端 Playwright E2E                   7/7 通过
```

接口实测：默认区间返回 2 天数据，支付 9950 分、退款 5970 分、净额 3980 分；CSV 表头与明细正确。

服务端测试覆盖支付/退款归日、净额、非法日期范围。

## 4. 限制

- 不含外部支付渠道流水比对；
- 未按渠道/套餐拆分；
- 未做定时邮件报表；
- 时区按数据库日期。
