## 1. 结论

**通过。** 管理端可按规则预览组卷结果，展示专题命中、题数、加权分、警告与题目明细；专题下线后自动恢复普通组卷。

## 2. 交付

- 新增「组卷预览」菜单与 `/quiz-preview` 页面；
- 表单覆盖孩子 ID、学段/年级、时长/门槛/每日上限、学科权重、趣味开关、种子、最大题数；
- 结果展示模式（专题/普通）、专题 ID/名称、题数、最高加权分、目标难度、学科分布、警告、题目表；
- 错误展示服务端 `code`、`message` 与 `warnings`；
- 复用已有 `POST /v1/admin/quiz/preview`，服务端无改动。

## 3. 验证

```text
npm run build     passed
```

浏览器走查（`http://127.0.0.1:5174/quiz-preview`）：

| 场景 | 结果 |
| --- | --- |
| 默认规则点击「开始预览」 | 普通组卷，5 题，最高加权分 9，警告含 `subject_shortage:english` 等 |
| 上线「E2E 预览专题」（5 道数学题）后预览 | 标题「专题模式：E2E 预览专题」，5 题全部数学，警告 `topic_mode` |
| 专题下线后再次预览 | 恢复「普通组卷」，无 `topic_id` |
| 重置 | 表单恢复默认并清空结果 |

> 桌面浏览器窗口最小化，无法截图；以上结果来自页面 DOM 文本与接口响应。

## 4. 限制

- 预览请求不会保存，也不生成答题会话；
- 同时命中多个专题时只能看到实际命中的一个，需下线其他专题对比；
- 孩子 ID 为空时按手选学段抽题。

## 5. 后续

- 支持从专题页一键「预览该专题」；
- 预览结果导出 CSV；
- 组卷历史与命中率统计。
