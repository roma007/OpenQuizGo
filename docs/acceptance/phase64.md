## 1. 结论

**通过。** 新增增长/漏斗/留存聚合接口与管理端「增长分析」页面，基于账号、登录会话、观看与订单现有数据，无新增埋点。

## 2. 交付

- `GET /v1/admin/analytics/growth?days=30`（`dashboard.read`，最大 90）；
- 每日新增账号、活跃账号、活跃孩子、支付订单；
- 漏斗：注册 → 有孩子 → 有活跃设备 → 有观看 → 有支付；
- 最近 14 天注册 cohort 的次日/D7 留存；
- 管理端增长分析页：漏斗卡片、留存表、每日趋势条。

## 3. 验证

```text
go test -p 1 ./...（测试库/Redis）      全部通过
管理端 npm run build                    通过
管理端 Playwright E2E                   7/7 通过
```

接口实测：`growth?days=7` 返回 7 天、漏斗 15/15/12/5/1、留存 2 个 cohort；`days=91` 返回 422。

## 4. 限制

- 活跃定义为登录会话/观看记录，不包含所有行为；
- 留存按登录会话判断，可能低估；
- 未做分渠道/套餐拆分与导出；
- 未引入埋点 SDK。
