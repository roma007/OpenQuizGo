## 1. 结论

**通过。** 管理端可分页查看订单并按状态筛选；已支付订单可模拟退款，会员到期时间按订单时长回退，退款后权益随到期状态失效；重复退款幂等。

## 2. 交付

- 迁移 `00013_membership_refund.sql`：订单状态增加 `refunded`、新增 `refunded_at`；
- 服务端：管理员订单分页/筛选、退款事务、幂等与非法状态校验；
- 管理端：新增「会员订单」页面，显示订单号、套餐、金额、状态、时间，支持退款二次确认；
- 家长端：订单状态新增「已退款」；
- 会员状态与权益沿用 015 的实时判定。

退款接口实测：

```text
支付月卡后：到期 2027-01-03（两笔叠加）
管理端订单页 → 退款
订单状态：refunded，退款时间已记录
会员到期：回退到 2026-12-04，状态 active
权益：topic_pack / report_advanced 仍然有效
重复退款：到期时间不变（幂等）
未支付订单退款：409 ORDER_NOT_REFUNDABLE
```

管理端浏览器：订单列表显示两笔已支付订单；对最新订单执行退款后，状态变为「已退款」，时间列显示退款日期。

## 4. 限制

- 退款为模拟操作，不调用真实支付渠道；
- 退款统一从当前到期时间扣减时长，不区分订单实际使用情况；
- 已使用权益产生的数据（如报告浏览记录）不会回收；
- 无部分退款、退款审核流。
