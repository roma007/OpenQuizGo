## 1. 结论

**通过。** 运营概览支持 7/30/90 天趋势切换，趋势条数与范围一致，非法参数返回 422，缓存按范围隔离。

## 2. 交付

- `GET /v1/admin/dashboard?days=7|30|90`；
- 趋势 SQL 动态天数，缓存 `map[int]cacheEntry`，每种范围独立 30 秒；
- 管理端 Segmented 切换，标题随范围变化；
- OpenAPI 补 days 参数与 422。

## 3. 验证

```text
go test ./...                                      passed
TEST_DATABASE_URL go test ./internal/dashboard     passed（7/30/90 + 缓存）
npm run build（管理端）                             passed
```

接口实测：

```text
days=7   → trend 7 条
days=30  → trend 30 条
days=90  → trend 90 条
days=15  → 422
```

管理端浏览器：切换「30 天」后趋势表 30 行，标题为「近 30 天趋势」。

## 4. 限制

- 90 天为实时聚合，未预聚合；
- 其他指标（会员、家庭等）仍为全局值，不随天数变化；
- 缓存 30 秒，数据可能滞后。
