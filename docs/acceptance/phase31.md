## 1. 结论

**通过。** 排行榜按战绩自动生成首胜、三连胜、十战、全胜、榜首勋章，随周期统计变化，家长端以 Chip 展示。

## 2. 交付

- `RankingEntry.medals`：5 类勋章；
- 服务端排序后计算，榜单第一获得榜首；
- 家长端排行榜卡片展示勋章，无勋章不显示；
- OpenAPI 补 medals 枚举。

## 3. 验证

```

```

## 4. 限制

- 并列第一时仅排序后的第一名获得榜首；
- 勋章按当前周期计算，切换周期会变化；
- 无勋章历史/解锁时间。
