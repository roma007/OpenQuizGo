## 1. 结论

**通过（单元测试 + 静态分析级）。** 规则保存遇到网络错误时暂存本地；规则页加载后回填待同步规则并展示提示条；联网后输入 PIN 同步，成功后清除本地记录。本地不保存 PIN。

## 2. 交付

- 新增 `PendingRuleStore`：SharedPreferences 键 `pending-rule:<childId>`，每个孩子只保留最新一条；
- 网络错误（`ApiException.statusCode == null`）自动入队，其他业务错误保持原提示；
- 规则页加载待同步规则并回填表单，顶部展示保存时间与「同步」按钮；
- 同步要求输入家长 PIN，调用现有规则更新接口；成功后清除并刷新；
- 成功正常保存时也会清除该孩子旧队列；
- 不持久化 PIN/令牌。

## 4. 限制

- 仅覆盖规则保存，不含设备临时解锁补发（另行设计）；
- 未做真机弱网/断网 UI 走查；
- 同步失败（4xx/5xx）保留队列并提示，无自动重试；
- `flutter build apk --debug` 本机超时，未完成构建验证。
