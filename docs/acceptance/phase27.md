## 1. 结论

**通过。** 家长端展示家庭内孩子对战排名，包含场次、胜/平/负、积分、当前连胜与最佳连胜；按积分/胜场排序并高亮当前孩子。

## 2. 交付

- `GET /v1/family/battles/ranking`：家庭范围、已完成对局统计；
- 积分规则：胜 3、平 1、负 0；当前/最佳连胜；
- 排序：积分 → 胜场 → 名字；
- 家长端对战入口新增「家庭排行榜」卡片与当前孩子高亮；
- 无对局时显示空态。

## 4. 限制

- 仅统计已完成对局；
- 排行按孩子维度，不含家长个人名次；
- 无时间范围筛选与历史快照。
