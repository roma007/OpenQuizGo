## 1. 结论

**通过。** 审计日志支持 `from`/`to` 日期范围，按当前筛选导出 CSV；日期边界与导出内容正确。

## 2. 交付

- `/v1/admin/audit` 增加 `from`、`to`（YYYY-MM-DD，含首尾）；
- `/v1/admin/audit/export` 导出 CSV（最多 5000 行，公式前缀转义）；
- 管理端审计页增加日期范围选择与「导出 CSV」按钮；
- 非法日期/结束早于开始返回 422。

## 3. 验证

```text
go test ./...                                      passed
TEST_DATABASE_URL go test ./internal/question      passed（日期/CSV 断言）
npm run build（管理端）                             passed
```

接口实测：

```text
from=今天&to=今天 → 2 条
from=明天         → 0 条
export?action=question.create → 200 text/csv，表头 + 2 行
```

管理端浏览器：日期范围控件与「导出 CSV」按钮存在。

## 4. 限制

- 日期按服务器本地时区；
- 导出上限 5000 行，超出截断；
- 导出为同步请求，大数据量会变慢。
