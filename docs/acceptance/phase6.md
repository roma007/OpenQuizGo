## 1. 结论

**通过。** 管理端可查看正确率建议、勾选并应用难度调整，服务端写入版本与审计。

## 2. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/admin/calibration/preview?min_answers=20` | 返回达样本门槛的在线题与建议 |
| POST | `/v1/admin/calibration/apply` | 批量更新难度，version+1，审计 `question.calibrate` |

规则：正确率 ≥85% 难度 +1；≤40% 难度 -1；否则保持。

## 3. 验证

```text
go test ./internal/question -run TestSuggestDifficulty   passed
npm run build                                             passed
```

浏览器实测（admin-web）：

| 步骤 | 结果 |
| --- | --- |
| 打开「难度校准」 | 1 题达样本门槛，1 题有建议 |
| 建议展示 | `导入题 1: 3+0=?` 难度 1→2，正确率 90%，建议提高难度 |
| 应用选中 | 确认后提示「已应用 1 题」 |
| 数据库 | `difficulty=2`、`version=2` |
| 审计 | `question.calibrate`，`after_data={"from":1,"to":2}` |

## 4. 限制

- 正确率长期不变时会持续给出同方向建议，需要教研人工判断；后续可加冷却期或一次只调一级的限制；
- 校准页截图因浏览器窗口最小化未能抓取，功能通过 DOM/接口与数据库验证；
- 仅统计在线题，样本门槛可调。

## 5. 后续

- 校准历史趋势与回滚；
- 按学科/学段批量策略；
- 与覆盖率看板联动（低覆盖 + 高难度提示）。
