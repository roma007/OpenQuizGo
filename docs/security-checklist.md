# 安全自查清单（T11）

> 第一期服务端上线前逐项确认；勾选项为当前实现状态。

## 1. 传输与凭据

- [x] 全链路 HTTPS（由网关/负载均衡终止 TLS，服务只暴露内网）
- [x] 访问令牌短期（15m）+ 刷新令牌轮换/吊销
- [x] 管理端令牌独立（type=admin），与家长令牌互不通用
- [x] 设备令牌随机 32 字节，仅存 SHA-256 哈希，解绑立即失效
- [x] 生产环境强制非默认 JWT_SECRET / 字段加密密钥 / 离线租约密钥
- [ ] 密钥托管接入 KMS（当前通过环境变量注入）

## 2. 身份与权限

- [x] 家长敏感操作（规则修改）需 PIN
- [x] 管理员 RBAC：question.read/write/review/publish/import、audit.read
- [x] 越权访问孩子/会话/授权均返回 404（不泄露存在性）
- [x] 管理员登录失败 5 次锁定 15 分钟
- [x] 短信验证码 1 次/分钟、5 次/小时

## 3. 答题与授权

- [x] 答案与解析在判分前不下发
- [x] 每题一次性令牌，重放 409
- [x] 服务端计时，<300ms 标记 suspicious
- [x] 会话 10 分钟过期；同设备单活跃会话
- [x] 授权签发串行化（孩子级 advisory lock），100 并发不超发
- [x] 心跳按服务端间隔计费，答题期间不计量
- [x] 离线租约 Ed25519 签名，过期/篡改拒绝（客户端验签）
- [x] 离线超额上报截断，重复对账 409

## 4. 数据与隐私

- [x] 手机号 AES-GCM 加密 + HMAC 哈希查询
- [x] 生日仅存年月；不采集位置/通讯录/广告标识
- [x] 日志不含验证码（mock 仅 dev 打印）、不含手机号明文
- [ ] 数据导出/删除自助入口（T12 前补齐）
- [ ] 数据库字段级加密密钥轮换演练

## 5. 依赖与运维

- [x] 依赖锁定（go.mod + go.sum）
- [x] 迁移幂等、可回滚脚本
- [x] 健康检查 / 就绪检查 / Prometheus 指标
- [ ] 依赖漏洞扫描（trivy/govulncheck）纳入 CI
- [ ] 审计日志保留 36 个月与访问控制

## 6. 压测前检查

- [ ] 预发环境关闭设备级答题限流（仅压测期间）
- [ ] 题库在线量足够，避免组卷 409 干扰指标
- [ ] 使用独立数据库与 Redis DB，避免污染生产数据
- [ ] 关注 p95、5xx、DB 连接池与 Redis 延迟
